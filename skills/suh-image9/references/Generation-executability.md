# 生成可执行性：风险提示与表达

生成风险用于判断本场哪些过程需要关注，不授予改镜或改戏权限。接手上游时，只落实已纳入当前有效设计的实现；风险旁的未采用备选仍是建议。独立创作及明确开放维度内的实现按本次授权完成，不重复求批。

## 1. 按需关注的生成风险

| 类别 | 相关过程 | 需留意的偏差 |
|---|---|---|
| 精细手部与交接 | 递物、接稳、解扣、写字、拨号 | 手指数量/穿模、物件凭空易手 |
| 多人肢体接触 | 拥抱、扭打、搀扶、牵手走动 | 肢体融合、身份互换 |
| 同框多主体各有独立动作 | 多人同时各做不同事 | 动作被平均化、有人静止或复制他人 |
| 画内可读文字 | 信件、屏幕、门牌、字条特写 | 乱码、字形漂移 |
| 镜面与透明物 | 镜子、玻璃、水面反射 | 反射与实体不一致 |
| 快速运动 | 奔跑、打斗、急转、摔倒 | 形变、动作不连贯 |
| 流体与粒子 | 倒水、烟、火、雨中细节 | 物理失真、落点错误 |
| 持续发言 | 单人连续说话及跨段接声 | 口型漂移、表情僵化或接声中断 |
| 运镜与人物运动叠加 | 环绕＋人物走位、推轨＋转身 | 空间扭曲、主体滑步 |
| 跨生成段持续动作 | 动作在段边界中间被切开 | 接续处重复起步或跳阶 |

是否发生取决于当前入口、素材与实际结果；清单没有通用秒数或主体数门槛。剧情需要的过程照常设计，风险提示不构成删除剧情、换说者或改结果的理由。

## 2. 分镜（场级导演）怎么用

- 仅对影响本场叙事或执行取舍的风险，简记具体过程与未核实条件；普通镜头不逐项打勾。
- 拆镜、改变揭示时点或改用后期文字属于导演方案取舍。只在获准设计的维度内提出；未采用方案与当前执行正文分开，改变已有设计按现有交接规则回传受影响范围。

## 3. Prompt 写清现有设计

以下原则服务于可读的执行描述，格式与 Cut 时间仍由 suh-promptskill 内的 `references/Output-format.md` 定义；分镜与Image9不依赖该文件运行。

1. **及时成立当前画面。** 首次相关动作前能读懂必要机位、主体位置与当前状态；已有共用条件沿用，变化处补清。这是描述组织，不是新增静止停留或全景开场。
2. **写清执行者与过程关系。** 多人、多动作可在同一 Cut 中展开，写清先后、同期及观看关注的变化；不按主语或动词数量拆镜，保留各参与者原有行动和发言。
3. **运镜用通用词并给方向和起落。** 优先用“固定 / 推 / 拉 / 摇 / 移 / 跟 / 升 / 降 / 环绕 / 手持”，加方向、相对速度（缓 / 匀 / 急）和起幅、落幅。不写焦距、FOV 等无依据数值（与原规则一致）。
4. **给必要结果可读的观看窗口。** 依采用的揭示时点、切点与实际覆盖安排，可以在镜内或跨镜完成；不要求每个 Cut 前移结果或单独收尾。
5. **情绪写成可见行为。** 延续原规则：用视线、停顿、手上的动作和身体距离表达，不堆形容词。
6. **写清必要物理阶段。** 交接写“握住—承重—松手”；倒水写起始容器与落点。只写本段真正存在的阶段。

## 4. Image9 怎么用

- 对上游标了 `生成风险` 的镜头，预演优先取能**区分风险阶段**的静格（例如接触前／承重中／离手后），方便事前检查。
- 静帧不证明运动；风险是否真的解除，仍以实际视频为准。

## 5. 边界

- 不新增任何平台私有参数（如运动强度、相机路径字段）；需要时由当前入口 profile 另行定义。
- 风险标注是设计信息，不是验收结论；没有真实媒体时，不能宣称风险已消除。
