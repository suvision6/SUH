# 代表性资产验证

用于新方向将扩展为一组资产、或多件各自好看却难以一起使用时。验证属于当前设计与制作，不是新审批部门，也不是要求先做齐人物、场景、道具三件套。事实与采用边界仍由入口负责。

## 先决定本次要检验什么

说明哪个设计关系需要证据，例如材料体系能否同时用于衣物和日常器物，人物进入场景后是否还读得清，或关键道具在使用尺度下能否辨认。不要写“检查美术质量”后把整片重做一遍。

从已有结果中选择能检验该关系的最小范围；不够时才在授权内试做必要部分。一个组合画面、同一对象的必要视图、或一组已有图并排，均可提供证据。哪种方式足够由问题决定，不规定对象类别、图数、分辨率或统一布局。

- 只有单件请求：检查它自身的用途，不扩成全片资产试产。
- 已有确认方向且相关使用已有可读证据：直接沿用，只检查新增差异。
- 概念阶段：可把代表性关系放进概念图一起讨论，不额外索要一轮批准。
- 仅文本任务或缺真实图：交付设计推演及下一步需要看什么，不声称通过图像验证，不阻断可做的文本。

## 怎样看实际结果

围绕同一问题看三个层次，可在现有图上完成，不要求分别产图：

**预期观看尺度。** 按当前使用情境看轮廓、比例、人物与环境的层级、关键道具或衣层是否能读清。目标观看尺寸未知时说明当前判断依据，不能仅放大细节就宣称远景可读。灰度或缩略图只在有助于判断时使用，不把所有对象都要求成最醒目的主体。

**设计细节。** 看连接、开口、厚薄、材料交界、磨损位置、握持和接触是否支持既定设计；美丽表面不能抵消功能和结构问题。静帧未展示的背面或内部不当作已验证。

**组合情境。** 把相关人物、服装、道具与场景关系放回同一用途下看：尺度是否相容，材料是否属于同一设计依据，光线差异究竟来自场景还是生成漂移。并排图只能支持其可比的部分，未实际合成或同场呈现时，不宣称接触与遮挡已证实。

涉及动作时，可用已授权静帧表达需要检查的起止关系，但不得凭静帧宣称布料运动、机械操作、口型或视频衔接已经通过。动态结果留给相应真实执行与查看。

## 问题决定修法，不按整批重做

区分共同设计不足与个别生成偏离。多个对象有同一问题时，定位共同的比例、材料或结构决定；单个画错就保护其他成功结果。用户已采用部分需要改变时，回到具体改变的授权，不借验证自行换方向。

反馈写成“观察到什么 → 影响什么 → 建议改哪一处 → 已正确的哪些保留”。这是设计判断；不能用标签、文件存在、色值统计或脚本 PASS 代替实际观看。

通过当前问题的检查后，沿已经确认的共同依据扩展有关资产家族，在同一清单中记录各对象差异和实际结果。新图仍是候选，不能因被选作工作参考就冒称用户已采用；正式交下游遵守原采用流程。保留成功基准，避免连续把失败衍生图当新标准。

还有未解决的问题时，只限制依赖它的批次，其余独立内容继续。验证不能变成无限试做或自动付费重试；执行和返修边界见[图像工作](image-work.md)。

## 留下可以接用的结论

在当前概念说明或相关资产条目中，用几句记录本次看了什么真实图或仅作了文字推演、检验哪一关系、支持到哪个范围、剩下什么。把必要的共同设计依据继续带给相关资产，不新增全库报告、统一评分或验收模板。
