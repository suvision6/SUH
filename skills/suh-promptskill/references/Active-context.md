# 恢复有效依据、局部变更与继续条件

本文件用于跨调用、部分采用或修订。普通单条独立输入只需保留其实际条件，不强迫建立大型项目档案。共同工具接口见[Workflow-state.md](Workflow-state.md)；它记录Agent的依据，不是自动调度平台，也不代替人类反馈。

## 有效依据与依赖

采用/入口与回流职责统一见 [Handoff.md](Handoff.md)。接续先恢复实际版本、范围、同场空间依据及已发生迁移；短独立任务保留必要条件即可。使用状态记录时，以artifact#unit登记实际内容/维度依赖，不笼统依赖全上游，也不漏掉真实接点。源字节变化和失效的处理语义见 [Workflow-state.md](Workflow-state.md)，它们要求定位影响，不等于全场重做。

## 具体变更如何处理

| 有效变化 | 要实际做什么 | 继续或回退条件 |
| --- | --- | --- |
| 人工仅改某一次发言 | 以发生位置及发言实例定位，更新该台词原字与该单位正文、预算和所有片段偏移；比较其他发言及未改单元 | 保持观看意图；容量不相容再处理开放分段，不能提速或删词；不因同一句在别处出现就一起替换 |
| 某角色表演特征或当前状态有明确修订 | 按[表演延续](Performance-continuity.md)区分稳定约定与本场变化，定位适用关系、触发和剧情时点，只更新实际依赖场次 | 一场的选择不自动成为长期特征；超出已明确授权、需要改变采用动作/台词/镜头/节奏或故事时，先交具体取舍待确认，不全局重写同名角色 |
| 仅改某处实物文字/尺度或一次焦点揭示 | 定位对象、时点与真实依赖，更新对应正文、参考职责及必要阅读/接续 | 不连带改对白、其他同字对象或镜头切点；已采用关键揭示改变回传该范围，不以新图自动覆盖 |
| 仅修合成边缘、材质或锚点 | 对齐母版和反馈版本，仅修目标属性及直接相关的光学/接触关系 | 保留既有摄影、表演、其他光声及成功部分；真实需要扩到原锁区时说明具体冲突，不自动全片重光 |
| 30秒条件变为20秒（举例，不是模型事实） | 重核每单位内容过程，不超限的保留；超限单位重新组织已开放生成边界，比较新的起末态 | 锁定长镜无法实现则交具体冲突，不能先拆摄影；设置值修改不代表相容性完成 |
| 横幅改竖幅 | 实际重读同框、手与道具可见性、视线关系；只修开放构图和受影响参考 | 锁定关系冲突返回分镜/用户，原词与情节保持 |
| 仅采用预演布局 | 读取布局facet具体摘要，更新相应人物/物件位置与接点 | 缺明确摘要先落实；不将图中摄影、外观、格数变成Prompt约束 |
| 前段错误尾帧 | 对齐实际结果所用输入，记录偏差与实际读取证据；依赖这张尾帧的下一段待修 | 未采用错误状态就不把错误写成下一段真相，也不能一边引用错误图一边宣称相反状态连续 |
| 用户明确接受错误结果的新持物方式 | 按实际接受的维度登记，修改真实受影响后段/素材 | 若牵连锁定剧情返回对应职责；没有要求接受的其他错误仍不采用 |
| 新导演稿改变揭示顺序 | 对应场及真实跨场依赖标待更新，等该范围人审 | 无关已采用单元保留；旧Prompt不能因已完成而继续作为有效执行稿 |

失效是提示需要重新判断，不自动改写正文。恢复也不能只将状态由红变绿：更新实际文件、记录采用依据、完成对应专业复读与依赖核对，才能继续。

## 接收修改与实际媒体

消息改词按发生位置执行；返还文件先保留，再按 [Review-delivery.md](Review-delivery.md)与导出基线提取正文差异及意见，不能按行号猜。采用与条件性继续遵Handoff。实际媒体先核对版本、实传素材与实读范围，再按 [Media-review-and-export.md](Media-review-and-export.md)定位执行偏差；没有新证据不自动重试。

## 最小完成记录

交接时足够回答五个问题：哪个请求和范围；依据哪份当前采用成果；现在交出什么实际文件/单位；哪些条件/素材未核实；下一动作是什么及由谁决定。更多内部字段只有在实际依赖或修复需要时保留。不要把这五问变成用户每轮必填表。
