# 侯孝贤

**标签：长镜头 / 中远景 / 深层空间 / 画外事件 / 段落省略**

## 时间与剪辑

- 一个镜头容纳完整生活状态和人物进出。
- 场景内部保持连续，场景之间允许巨大时间跳跃。
- 不用反应镜头规定观众关注对象。
- 重要事件可发生在画外，稍后才显示结果。

## 摄影机运动与视角

- 固定远观为基础，必要时缓慢横移或摇摄。
- 摄影机先观察环境，不追逐人物。
- 人物离开画面后，镜头仍可停留。

## 构图、空间与调度

- 中远景、深景深、多层门窗和前景遮挡。
- 前中后景可同时发生独立行动。
- 人物自由进出画面，调度承担主要剪辑功能。

## 适用

- 家族历史、社会群像、时代变迁、需要时间重量的告别。

## 禁止

- 只追求镜头长；
- 画面内部没有状态变化；
- 用漂亮自然光掩盖调度不足。
