# 概念与设计

用于方向探索、人物／服装／场景／道具的新设计和设计不足的定位。入口负责事实与采用权限；本文件负责怎样提出、深化和判断设计，不负责平台参数或另设确认程序。

## 从故事提出设计问题

先用已有资料说清：哪些是不可擅改的事实与选择，哪些仍开放，以及本次设计要让观众感受到或理解什么。把开放问题落到对象与关系，不停在“高级、史诗、电影感”；不要求用户逐栏回答。

从故事因果中找可用的设计起点：物件由谁制造、使用和维护；衣物怎样适应身体与活动；空间如何接纳、阻挡、分隔或暴露人；资源、技术和时间怎样留下痕迹。没有依据的背景解释标作提案，不为显得专业编造历史、身份或仪式。

本次可用性的判断应具体，例如“持物方式不遮住需要辨认的部位”“人物在空旷空间里显得无处停留”。审美方向仍需专业判断与用户选择，不能把它缩成字段齐全或自动分数。

## 方向未定时主动探索

先识别最容易落入的常规答案，再寻找同一问题的其他解法。常规答案是比较基准，不是禁用项；用户明确要熟悉、简洁或传统的处理时，准确完成比刻意猎奇重要。

根据开放问题选择有用的探索方式，不必逐种执行：

- **换组织方式：**保持故事功能，改变空间层级、形体组合、穿着结构或操作方式。
- **换形成原因：**比较不同材料来源、加工、装配、维护方式怎样改变外观；不是只替换材质名称。
- **借跨领域关系：**从建筑、服装、工业设计、日常器物或自然中寻找能解决同一问题的结构关系。借用怎样工作，而不是硬拼两个题材或照搬完整作品。
- **调整未定条件：**在未锁定范围内改变一个有意义的比例、密度、分布或显露方式，看它怎样改变感受与用途。

参考搜索应围绕问题与具体特征，不只重复题材关键词；已有参考先看清再取用。可先独立推导再对照参考，避免第一张图把所有方案定成同一个样子。参考职责与读取限制统一按[图像工作](image-work.md)处理。

先形成候选，再筛选给用户看。判断差异落在什么可见结构或关系上；若只是同一方案换名称、种子或装饰，合并为变体。配色或灯光本身就是用户本轮问题时，认真比较该维度，不因“只是换色”否定有效任务。

提交时说清本轮比较的内容，给每个留下的方向一个可讨论的名称、具体做法、故事理由及主要取舍；表达尺度尽量相近。不提交故意较差的陪衬方案，也不把搜索结果列表当创作成果。数量随任务，推荐可说明理由，但不伪装成用户选择。

用户可以选方向、指出只取其中一部分，或否定本轮比较问题。沿真实反馈继续：记录哪些已定、哪些仍开；混用两案时核对形体、材质和空间是否相容，不机械拼接。没有反馈时可保留推荐候选和明确标注的试做，不能自动升为正式采用稿。

## 把方向变成能继续设计的体系

用几条与本项目有关的关系组织设计，落实到当前需要的对象。下表是判断工具，不是强制填写表；无关维度省略。

| 维度 | 要做的设计决定 |
| --- | --- |
| 形体与比例 | 大小体块、轮廓、疏密、重复与例外怎样组织；需要辨认的部位在哪里。不把圆、尖、方固定等同某种性格。 |
| 明度与色彩 | 谁突出、谁融入，环境与人物怎样分层；明暗、颜色的关系怎样随场景变化。颜色不直接等于材料，也不要求固定百分比。 |
| 材料与构造 | 刚柔、厚薄、连接、接缝、表面反应与磨损的原因是什么；同类工艺在不同对象上如何延续。 |
| 细节与表面 | 哪些地方值得精细，哪些保持安静；装饰、修补、污损是否有用途与位置依据，而非全画面均匀加噪。 |
| 人与空间 | 人怎样站、坐、走、取放和看见；入口、尺度、通路与遮挡是否服务既定行动，不能自行改人物调度。 |
| 观看与氛围 | 当前视图要显露什么设计，光线怎样呈现材料与层级；遵守已定摄影，不能拿换镜头替代改设计。 |

共同依据不等于外观一样。人物、群体和空间可以共享材料来源与构造逻辑，同时通过维护、比例、穿用方式和资源条件形成差异；不得自动给所有对象加同一纹章、色块或装饰。

把真正有用的决定记在现有概念说明或对应资产条目中，并说明适用对象与场次。不另建平行的强制设计数据库；后续对象沿用共同依据，只写自身差异。

## 深化到具体对象

**人物与服装。** 从体型、活动、身份与生活方式决定衣物体积、剪裁、层次、闭合方式及穿着习惯，再选择面料与加工痕迹。细节应服务辨识或用途，不通过随意加包、武器、饰品来“丰富”。检查动作需要的部位、关键衣层和面部是否会互相遮挡；已确认的脸、体型或服装不能连带重做。服装设计不等于安排走秀或表演。

**场景与建筑。** 先明确体量关系、进出与停留、层级和关键使用位置，再设计构造、材料、开口、家具与陈设。物件摆放应体现使用而非装饰填空；有意空旷也要成立。已定空间从同一依据推导各视图，缺哪个隐藏结构才补哪个，不以一张气氛图猜完整建筑。

**道具。** 从尺寸与使用动作确定重心、握持／连接部位、开启或承力关系，再做材料和表面；叙事依赖的细节需在预期观看下可读。图案应有具体组织方式，不能用发光纹样掩盖形制未解决。未涉及真实制造时不硬加工程图或毫米尺寸。

**组合。** 检查人物、衣物、物件与空间共同出现时的比例、接触、辨识与材料关系。单件成立不代表组合成立；具体检查见[代表性资产验证](representative-check.md)。

## 项目针对性评审

在呈现方向前和设计扩展中判断，不新增一轮用户审批：

- 去掉项目名称后，这个提案是否还能原样套给大量项目？若能，找出与本故事或人物有关、尚未表现出来的具体关系；不靠新添标志或复杂度制造“独特”。
- 这个方案是否说得出一个清晰的设计构思，并且在形体、构造或空间中看得见？若只剩摄影、调色、雾和形容词，回到尚未解决的设计。但用户只要照明／氛围研究时，不强行新增物件造型。
- 各对象是否支持方向，而非几个无关的“亮点”竞争？有意的冲突或差异若服务故事，应保留，不强制全片只允许一种表现。
- 是否用气氛藏住了关键功能，或把用户已采用的自然、平静、普通处理误当作缺陷？先满足本次表达，再判断是否需要强调。

发现问题，给“具体部位或关系 → 为什么损害本次目的 → 最小有效设计修改”。例如，轮廓辨识弱先看体块连接与留空，不默认加金属装饰；空间空泛先看尺度与使用关系，不默认加杂物。取舍有不确定性时说清，不把审美意见包装成客观测试通过。
