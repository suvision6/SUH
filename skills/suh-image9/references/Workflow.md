# 从剧本到可用宫格预演

先区分本次要完整覆盖，还是只回答一个局部问题。完整整场/整段请求走下方第1—7步；明确的局部快检走本节即可，不额外补做完整流程。两者沿用相同的来源、状态恢复、参考职责和真实媒体证据边界。

## 按需快速局部静态预演

1. **定范围与问题。** 写清来源/有效版本、指定镜头或接点和要判断的关系，例如“C02初触时能否看清交接”或“C03→C04视线是否相承”。继承当前分镜/Prompt的有效摄影与状态，不把检查改成另一套拍法；未采用对照另列。
2. **补足必要上下文。** 只读目标及影响判断的前后状态、空间锚点、人物/手物归属、相机位置/方向与信息锁点；检验接点时两侧都读。现有片段已足够就开始，不要求整场剧本、完整资产包或全场台账。缺普通外观可作少量明确暂设；缺失条件若会改变检查答案，先从已有材料补读，仍缺再问那个具体问题，受影响结论保留未验证。
3. **取必要静格。** 依检查问题取一个时点或几个有区别的时点；单格、双格、小组均可，不固定九格或每镜三格。每格一个时点，保留源镜定位与同镜/切镜关系；按[状态与投影](Spatial-and-state.md)恢复本格状态、可见面和遮挡，按[简笔表达与参考职责](Style-and-reference-roles.md)统一黑白低细节表达。需读更多背景不等于需把背景全画出来。
4. **完成本次输入与检查。** 按[单格/整页输入](Input-and-delivery.md)写目标的自足正文；小组用合适版式，单格不要求九槽页面。读回目标和必要接点，只回答声明的问题。已获对应图片生成/编辑授权时，可在本次范围文字输入可用后按[媒体执行链](Media-execution.md)执行，无须等整场方案；无授权则交局部设计检查及绘图输入。
5. **按证据回交。** 交本次范围、必要简格或绘图输入、具体发现/修订建议、仍未验证项。区分文字设计判断与已实际看图的结果，列明没有检查的镜头/维度；不把局部成立说成整场通过，不把静格说成运动或节奏已验证。工具失败、尚未出图或图不可读时如实写明，只保留有证据的文字结论；未知任务先查原任务，不自动重发或伪造成功。将证据和建议定位到对应分镜/Prompt范围，交本次成果供用户确认；不自动采用、不自动改写上游或触发下一Skill，可由用户人工衔接，不拆成逐格审批。未运行Image9不阻塞主线。

简短交付可直接用“范围与依据 → 必要静格/输入 → 发现与未验证项”三段。完整预演仍用下列流程及原[主稿模板](../templates/Previs.md)，不把快检的精简输出套给整场请求。

## 完整预演流程

## 1. 读源后就建立可工作的依据

**目标**：读源后建立可继承、可定位、含空间概念的工作依据。

**输入**
- 按 [Handoff.md](Handoff.md) 确认的请求路线及当前有效来源。
- 已有对话/文件中的范围、源版本、用户修订、画幅、用户明确指定的风格和参考。
- 导演稿或当前Prompt（如有）；已有跨调用记录（如有）。

**必做**
- 独立预演可直接进入。
- 接收导演稿或当前Prompt时，先恢复其版本、锁定与有效开放摄影增量。
- 已有跨调用记录时才用 [Workflow-state.md](Workflow-state.md) 恢复。
- 从已有对话/文件继承范围、源版本、用户修订、画幅、明确风格和参考。
- 按[简笔表达与参考职责](Style-and-reference-roles.md)确定本轮画法和参考分工。
- 输出一段“本次依据与开放项”，区分：原稿明确事实、已采用的导演决定、本轮为预演暂设。
- 直接剧本没有机位时可主动设计。
- 缺人物图可用少量暂设轮廓。
- 只有影响核心事实的矛盾需要问；不相关工作继续。
- 把全文中行动、对白、画外声、静默、揭示与结局定位到自然段或简短源标识。
- 定位目的：最后能回答“这段在哪里表现”；不是每行都建表。
- 机器交付器的 source_units 是Agent建立的定位辅助；录入本身也要对原文回读。
- 精确镜头先提取保留项：源镜、景别/视点、轴侧、动作阶段、真实时间或顺序要求、画幅。
- 场级稿提取完整场级导演设计：关键景别、视点方向、观看递进、切换及明确允许变化的摄影范围。
- 与主线协作时，实际读取当前有效导演稿，继承其布局、手位、揭示与接点。
- 明确要求独立对照时才分列两套依据。
- 没有指定时长，按表演过程给暂估范围或相对先后。
- 设计调度与候选镜头前，按[共享空间依据](Spatial-basis.md)恢复上游有效空间、来源版本及暂设。
- 独立剧本入口先建立最小合理布局；无图仍需要空间概念。
- 原文锁定与已读证据优先，暂设要明确。
- 把可继承依据留在主稿。

**禁止**
- 另作独立方案（或另开一套独立剧本候选）却声称检查/验证了主线。
- 把前页成图的画风误当用户偏好。
- 重复提问。
- 为暂设轮廓添加新剧情身份。
- 因所有录入单元被引用就声称全文无遗漏。
- 擅设 15/30 秒时长。
- 用身份图替代全屋布局。
- 为了同框倒推改造空间。

**完成判据**
- 已输出“本次依据与开放项”，三类内容分开。
- 全文行动、对白、画外声、静默、揭示与结局已定位到源内容；此步不预定镜头、画格或表现落点，成稿读回时再核对覆盖。
- 精确镜头保留项或场级导演设计已提取；协作时已继承实际导演稿。
- 空间依据已恢复或已建最小合理布局，暂设已标明并留在主稿。

## 2. 先设计一段可以看的戏

**目标**：从人物目的与阻力出发，把内容组织为可走通、可观看的候选镜头。

**输入**
- 第1步的依据、空间布局与（如有）已采用合同/锁定决策。

**必做**
- 逐段确定：此刻观众需要知道什么、仍不应知道什么、在看谁的反应。
- 把相邻内容组织为候选镜头。
- 同一观看位置能同时呈现行动与反应、且停留能建立关系时，允许持续。
- 只有切换确实改变观众获得的信息、靠近关键反应、接续动作或显示被遮挡内容时再切。
- 动作与感受可不同刻可见：可先听画外声再看反应，也可保持听者画面。
- 采用上述处理时必须写原说者及可见范围。
- 暂设调度要能在已知空间走通，有进入/到达。
- 先检查人物从初位沿通路到停点、摄影机落点与取景方向、遮挡/视线能否容纳该构图和运动。
- 再写连续观看简述和镜头序列。
- 对每个候选/采用镜头说明：观看对象、景别、机位与视点方向、开始/结束状态、整场作用。
- 景别递进与切换落到实际观看过程。
- 镜数、焦段和形式依据本戏。
- 精确稿在实际采用合同内做镜内解释。
- 保留已采用的机位、切点、时点及运动含义。
- 只在合同确立一源镜一Cut时继承该约束。
- 发现锁定决策有问题：把问题和替代方案独立列出。

**禁止**
- 因为一句新对白/一个动词自动切镜。
- 靠切镜让人穿过桌子或瞬移。
- 在调度与观看过程尚未成立时，无依据地过早锁死每秒；已有明确时点和已采用时间要求仍须保留。
- 留下由下游任意补全的关键摄影。
- 套固定镜头菜单。
- 从“精确输入”自动推定一源镜一Cut。
- 悄悄实施对锁定决策的修改。

**完成判据**
- 每个候选/采用镜头均有五项说明。
- 调度与摄影已在空间中检查可行。
- 每次切换都有信息/反应/动作/遮挡上的理由。
- 锁定问题（如有）已独立列出问题与替代。

## 3. 从连续镜头取静格

**目标**：从每个镜头取出能区别关键阶段的静格，并逐格恢复当前状态。

**输入**
- 第2步的镜头序列；[状态与投影](Spatial-and-state.md)规则。

**必做**
- 每镜挑能区别关键阶段的时点（举例见 [Workflow-examples.md](../examples/Workflow-examples.md#静格时点举例)）。
- 纯停留用一格加声音/停留区间即可。
- 给格标稳定定位（如 F003）；页槽另记。
- 给本次镜头独立标识（如 PV03）；已有源镜另外保留。
- 前后关系只用实际含义：首格、同镜继续、切镜、有依据的省略。
- 同刻摄影备选放在序列之外。
- 每格只画一瞬。
- 摄影机移动用文字描述其镜内路径，并取某个位置。
- 按[状态与投影](Spatial-and-state.md)在主稿分段保存稳定依据与全场状态档案，再按叙事时点恢复。
- 逆序回补不受最后成图状态影响。
- 逐格恢复当前必要状态：谁在哪里、身体/头部朝向与目光对象、哪只手拿什么。
- 同时恢复：接触/承重、门帘开闭、可见/遮挡、光源是否发生剧情变化。
- 固定同镜保留未动背景的投影与相对尺度。
- 运动同镜取实际摄影路径位置。
- 换镜重新推导画面左右。
- 把结果写进页/格正文；此步由Agent完成，工具不会代做。

**禁止**
- 只有一次状态变化时硬取三格。
- 仅用 P01-F03 这类会随分页改变的标识作为格身份；它可保留为页槽标签，与稳定格ID对应。
- 要求一张图同时拥有运动起点和终点。
- 运动同镜为每格重新居中。
- 把全场档案复制进页/格正文。

**完成判据**
- 每格有稳定定位，镜头有独立标识，源镜标识另存。
- 每格只表现一瞬，状态逐项已写入页/格正文。
- 同镜/换镜的投影、尺度、左右已按规则处理。

## 4. 分页并写可直接使用的绘图任务

**目标**：按序分页，写出每页可直接复制使用的绘图正文与声画主稿。

**输入**
- 第3步的格序列及状态；[Input-and-delivery.md](Input-and-delivery.md) 装配规则。

**必做**
- 按序分页，每页最多为本页版式的格数（默认3×3九格；用户指定版式时按其行列）。
- 页边只是排版边界；同镜跨页继续原状态与摄影路径。
- 按 [Input-and-delivery.md](Input-and-delivery.md) 装配每页复制正文：排布/画幅/简笔表达、参考取用部分、稳定身份/必要空间、页首状态、逐格可见内容、未用槽与共同约束。调整行列或页槽时，同步实际页正文；脚本不自动重写排布说明。
- 声画主稿另写声音一次播放的位置/跨格范围和并行关系。
- 非语言动作、环境声与说话可并行。
- 静默按原稿保留。
- 无实际音轨时，暂估仅用于设计阅读。

**禁止**
- 对白因同镜三格而出现三次。
- 无实际音轨时承诺口型或精确时长。

**完成判据**
- 每页格数不超过本页版式格数，顺序与格序列一致。
- 每页复制正文可独立使用，与本页行列和完整页槽对应。
- 每段声音只播放一次，位置/跨格范围与并行关系已写明。

## 5. 成稿前做一次连续读回

**目标**：把主稿当连续影片、把每页正文当独立绘图请求各读一遍，修正后交付。

**输入**
- 主稿、实际页/格复制正文、[最终文本投影核对](Spatial-and-state.md)规则。

**必做**
- 先把主稿当连续影片读：遮挡前后、视线对象、信息先后是否接得上。
- 同时检查：情绪落点、声音跨镜和动作阶段是否接得上。
- 对照第1步的源定位，确认行动、对白、画外声、静默、揭示与结局均有表现落点；画外声与未单独取格的连续过程可在声画主稿中交代。
- 再把实际页/格复制正文当独立绘图请求读。
- 确认简笔表达、逐张参考职责与当前状态已展开。
- 执行[最终文本投影核对](Spatial-and-state.md)：从实际机位/朝向推画面左右。
- 连同脸、肩、手、目光和遮挡对照相关画格。
- 同镜多格比较固定物尺度/投影及人物相对锚点。
- 跨页连读页尾→页首；运动格对照路径位置。
- 检查落在真实待交正文上。
- 将必要推导与格定位留在简短检查记录中。
- 无图时只称“文字设计核对”。
- 发现漏项：补主稿并重新派生受影响输入。
- 发现空间不可能：先修候选摄影/调度。
- 问题来自源稿矛盾或锁定冲突：列出最小冲突，保留未冲突部分。
- 交付内容：主稿 + 所有实际页的完整复制输入 + 真实未验证项；本次成果交用户确认，不自动采用或推进下一Skill。
- 需要批量时运行本地交付器并回读导出，报告实际路径。
- 没有实际图片时，交付名称为“预演设计及绘图输入”。

**禁止**
- 正文中夹带全场历史或不属于目标格的未来动作。
- 用参考 purpose 记录替代实际正文。
- 只读空间总述就当作完成检查。
- 用负词遮盖空间不可能。
- 为了整齐页数漏掉结尾或声音。
- 没有运行交付器却声称文件已生成。
- 没有实际图片时称“画面已验证”。

**完成判据**
- 两遍读回均已完成，检查记录含必要推导与格定位。
- 发现的问题已按类型修复或列为最小冲突。
- 交付物齐全，批量导出（如有）已回读并给出实际路径。

## 6. 修改后仍是一套能用的稿

**目标**：按原因分类修订，修改后主稿与各页输入仍保持一致可用。

**输入**
- 修改对象、实际输入及前后格；[媒体原因分类](Media-review.md#原因分类与修订影响)。

**必做**
- 读取修改对象、实际输入及前后格。
- 按[媒体原因分类](Media-review.md#原因分类与修订影响)区分来源矛盾、输入错误与图像偏差。
- 缺图/缺实际调用证据时，原因保留未定。
- 按 [Spatial-and-state.md](Spatial-and-state.md#修复保持有效成果) 修目标、主稿依据及受影响页/格输入。
- 修改后对照旧版。
- 有真实目标图才写修图；无图写替换输入。
- 镜头改变时重建实际时点与声音关系。
- 保留稳定源定位。
- 批量载体直接改正文后，按 [Media-execution.md](Media-execution.md#修改正文后的派生协调) 处理待核。
- Agent专业复核可确认无需改图。

**禁止**
- 把分页当剪辑。
- 把本次修订成果的一次人工确认拆成逐格或多级审批。

**完成判据**
- 原因已分类或明确保留未定。
- 受影响页/格已更新并与旧版对照。
- 已依 [Handoff.md](Handoff.md) 回交当前版本、变化及未决范围，等待用户对本次物料确认后决定后续衔接。

## 7. 实际生成与版本回流

**目标**：在授权范围内实际生成图片，并让版本与采用记录回流。

**输入**
- 完整文字方案；明确的图片生成/编辑授权；[Media-execution.md](Media-execution.md)、[Media-review.md](Media-review.md)。

**必做**
- 仅在完整文字方案之后、且在明确图片生成/编辑授权范围内执行。
- 顺序：核实宿主能力与真实参考 → 准备当前输入并绑定授权 → 调用前登记start。
- 接着：宿主单次提交 → 记录真实回包并回收图像 → 保存版本。
- 接着：按 [Media-review.md](Media-review.md) 观察实际图与整段 → 必要局部修复并复看接点。
- 最后：记录真实人类采用。
- 台账、防重发、版本与采用机制见 [Media-execution.md](Media-execution.md)。
- 状态未知或进行中时，先查原任务。
- 无授权时仍交完整文字预演。
- 媒体记录服务专业成果。

**禁止**
- 超出授权范围生成/编辑。
- 状态未知或进行中时重复提交。
- 把每格变成审批表。

**完成判据**
- 每次调用前有start登记，调用后有真实回包与已保存版本。
- 采用记录来自真实人类采用。
- 无授权时已交付完整文字预演。
