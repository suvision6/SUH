# 叙事动态预演

版本见 [VERSION](VERSION)。保留能连续阅读、能定位修订的完整预演，也支持围绕一个具体问题的局部静态快检。默认白纸黑白导演简笔分镜，用粗略大形、低细节人物和必要空间锚点辅助检查分镜与Prompt；不以精细美术资产为交付目标。完整预演默认3×3分页（可指定行列各1—4）；快检只取必要单格或小组，不凑九格。用户明确指定的媒介与画幅优先。动态指叙事与时间组织；静图不证明实际运动、口型或真实节奏。

## 职责与条件路由

先按实际请求选择 [工作流](references/Workflow.md) 的范围：

- **完整预演**：用户要整场/整段时，完成连续观看方案、镜头与镜内时点、声画主稿和所有实际页输入；沿用完整七步，不自行缩成抽查。
- **按需快检**：用户只要检查指定镜头、接点、空间或动作关系时，读取目标及足以判断它的上下文，完成必要简格/绘图输入与范围明确的反馈；不索要整场全套文件，不展开无关分页。快检是工作流可选旁路，未使用Image9也可按用户确认结果进入Prompt；一旦使用，本次成果交用户确认。

两种范围均继承来源权限：直接剧本可主动设计观看与调度；场级稿继承已采用的关键景别、视点方向、递进与切换，只在明确开放范围提出摄影候选；精确分镜继承实际采用的摄影、切点和合同，镜内仍可多格。混合稿逐项识别。

先完整读取本入口与工作流的当前入口及适用步骤。下列明确要求“读”的触发条件成立时，对应参考为本轮必读；原有“可选/选读”仍按需要，不额外加载无关方法。只读开头、搜索片段或收到截断时补齐缺失部分，不能以命令成功或自报已读代替实际返回。连续上下文内完整内容仍可用且版本未变可复用；上下文压缩后恢复、换入本Skill、版本变化或内容可用性不明时，重读入口、适用参考及当前采用正文。不可读处说明影响，不凭记忆补作已读；简记实际依据与缺口即可，不新增读取表。

按当前任务读取：

- 观看、镜头与画格、声画关系：[叙事与画格](references/Narrative-previs.md)。
- 调度/机位前继承或建立最小合理空间：读[共享空间依据](references/Spatial-basis.md)。写页/格正文时按[状态与投影](references/Spatial-and-state.md)恢复当前时点，重点处理接触、视线、反打与同镜多格/跨页。
- 写页/格前读[简笔表达与参考职责](references/Style-and-reference-roles.md)：场景、人物、服装、道具各取指定部分，统一简笔表达；多页身份全局一致。
- 每页完整输入与局部替换/修图正文：[输入与交付](references/Input-and-delivery.md)；成果组织用 [模板](templates/Previs.md)。
- 上游标了生成风险的镜头，优先取能区分风险阶段的静格：[生成可执行性](references/Generation-executability.md)。多场/多集身份一致优先取 [项目设定](references/Project-bible.md)（可选）。
- 批量文字落盘：[交付器说明](references/Delivery-tool.md)和 [本地脚本](scripts/deliver.py)。
- 已获具体生成/编辑授权：[媒体执行链](references/Media-execution.md)；已有实际媒体：[媒体审阅](references/Media-review.md)。

## 贯穿工作流的约束

- 默认原字对白、原说者、原语言及声画位置。疑似错字/语义问题另列建议，未经确认不改；明确新增创作授权除外。对白与估时按 [共享规则](references/speech-and-dialogue.md)，不为填格、塞时长删词或加速。
- 必要摄影方法选读 [DP](references/Dp-reference.md)，观看设计选读 [导演方法](references/director-methods.md)。以当前戏落实机位、光线、空间或观看决定，不机械要求选人名，不全部加载或套统一光型。
- 每格一个时点/视点。稳定身份/空间、状态回查与当前绘图正文分开（完整预演保留全场档案，快检只保留必要状态），脚本不自动选时点或隔离误放进正文的档案。同镜多格按固定摄影或真实运动位置展开；场景左右、对象左右、画面左右分别推导到脸/肩/手、目光和遮挡。反打不镜像房间，画外人物不自动消失；参考只按指定职责使用，摄影职责须另有采用依据。
- 简笔表达保留当前景别内关键开口、台面、通路、道具、接触与遮挡；取景与动作冲突回传，不为可见而擅改上游景别构图；不把生产编号、台词或气泡画进净图，剧情实物文字按来源。
- 图片生成和编辑仅按明确范围授权调用实际宿主工具；本包脚本只准备、登记与排版，不含provider SDK。视频、延长和无授权重试不在此路径。不能把本地路径当真实已附图，不能把模型参数名当真实后端。真实图片可选择同源PDF／HTML审阅，格式未锁为默认；文字输入不伪称图片已出。
- 独立剧本预演可完整设计调度、观看、摄影与切点；接收采用稿时，仅明确开放范围允许提出候选，不能因“场级”名称自行解锁摄影。事实一致与艺术取舍分开。错误媒体的错误维度不能升级为新依据，前页风格不合格不能作画风参考。没有实际媒体只交设计检查，不声称动态、视觉或人工验收通过。

与其他 Skill 协作或接收局部采用时读 [交接规则](references/Handoff.md)；已有跨调用记录才读 [工作流状态](references/Workflow-state.md)。每个Skill本次物料产出都交用户确认，可由用户人工衔接下一Skill；Image9可跳过，一旦运行则交本次快检/完整预演结果供人工审阅，不按格增加多重审批。Image9自查或图像采用不能替代分镜审阅，不能自动采用、改写分镜/Prompt或推进下一阶段。独立完整预演继续可直接进入。

已有当前Prompt时，按交接规则接收其有效开放摄影增量与上游导演锁定，再恢复预演时点；不是把生成段逐段转成Cut，也不退回另写一套无关摄影。

需理解完整交付尺度时读 [双页剧院案例](examples/Theater-previs.md)；需追溯官方吸收与排除读 [规则来源](references/Rule-sources.md)。案例是示范，不是镜数、机位或时长配额。业务范围为剧情类影像，不限片长与集数。
