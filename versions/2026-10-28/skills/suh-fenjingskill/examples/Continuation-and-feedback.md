# 场级创作、审阅和修复的连续使用示例

历史示例来源：调试组件0.0.2，经0.0.3修订；当前入口与确认顺序适用0.0.4候选，原导演正文保留。案例R号是创作修订号。

以下是虚构的作者示例，所有“用户反馈”均为模拟；不是实际采用证据。展示的是导演专业工作如何连接主线，不规定每场固定镜数、秒数或载体。

## 输入与本次完整导演候选

原稿：夜，校舍器材室。岑宁站在柜前，左手托着未开盖的录音机。姚澄在门内侧。岑宁：“你说过，不会再放出来。”姚澄没有解释，先看门锁，再伸出右手；手停在录音机前，没有接。走廊钟声响了三下。岑宁听完才将录音机放回柜内，合柜但不锁。姚澄：“我没答应过他们。”岑宁不回头：“那就别答应。”

请求：整场导演稿，后续再做Prompt；不露脸的走廊没有第三人，不指定导演姓名。

### 先讨论方向，再写正式稿

Agent短提案：“这段可按克制的关系悬疑处理：追究承诺、伸手却未接、收回录音机，最后关系仍未解决。重点让观众读到两人和录音机的距离，不把看门锁解释成罪疚，也不补‘他们’的画面。保留钟声和原词，按这个方向做本场分镜可以吗？”

模拟用户：“可以，按这个方向。”这只确认本场方向。随后才形成下面的正式导演候选，成稿仍待用户确认；此模拟反馈不能登记成真实项目采用。

### S01｜候选导演稿，待审

整场观看从岑宁对承诺的追究，转到姚澄无法完成的接物，再以录音机被收回但柜未锁保留两人关系的未决。姚澄的话是他的声称，不补拍“他们”、电话、往事或实际外传证据。

本稿必要照明暂设：柜与门之间的室内顶灯向下照亮两人所在的活动区，室内侧浅色墙面反射补到人物侧脸、门锁及手中录音机。灯位与照入方向全场沿用，合柜后仍能辨认柜门和未锁状态；不把这些暂设称为原文已给条件。

从人物连线室内侧用中景同框建立柜、录音机和门内姚澄的距离，首句在此完整发生。岑宁左手托着未开盖录音机，身体朝柜、上身略向姚澄；这是让发言与关键持物同时可读的候选调度，不是源文额外事实。她看着姚澄，完整说：“你说过，不会再放出来。”

姚澄不解释。观众要看到他的目光先落到门锁，然后右手才抬起向录音机伸去；镜头不能先用手部特写抹去看锁的动作。手停在录音机前，不接触、不接走。看锁后切到含手、物和岑宁侧身的较近关系景别，保留手、物和双方距离的观看，手停下后不添加握拳或抖动来解释罪疚。

走廊钟声响三下；用室内的两人承受这段时间，不切出去揭示没有的第三人。三声钟期间保持较近关系观看，岑宁完整听完三声，随后转回能见柜门及双方的中景，把录音机放回柜内，左手离物，再合上柜门。柜没有上锁：最后一个必要观看必须足够看清合柜结束后没有锁柜动作，不能用摇走镜头来掩盖不明确终态。

姚澄仍在门内侧，说：“我没答应过他们。”岑宁不回头，答：“那就别答应。”结束保留她朝柜、他未接到物的关系，不补和解、转身拥抱或离开。

锁定：看锁→伸手→停而未接；三声钟全部听完→收物；柜合而不锁；后两句的顺序与岑宁不回头。关键设计：室内侧中景建立关系；看锁后较近关系景别；收物回中景并保持至后两句结束。开放：在这些采用设计和同一空间关系内微调机位、实现运动并组织生成分段，不改变已有镜头/Cut关系，不预定生成段数。照明沿用上述本场暂设，不套夜景默认冷蓝、浅景深或背光；后续摄影细化须保留光源关系与关键可读性。

时间依据：未知钟声实际间距和实读速度，因此不报精确总秒数。三声钟为完整独立过程，收物合柜在其后；姚澄看锁和伸手的先后不可借“都是动作”压成同期。原词在本候选按次序各出现一次。若用户要求硬片长，先取得本项目假设或实读，再评估冲突，不直接加速台词。

复核：原稿里的未开盖、未接、未锁、不回头均有正文对应。正文只证明设计，真实持物可见、钟声长度与表演须后续验证。

### 此时 Agent 的实际下一步

交上方完整候选，停止在分镜人审点。不得已经写Prompt候选；无须强行调用Image9。可保存主稿、来源和本次范围，选择所需载体，而不是让用户搬运整份条件。

## 模拟反馈和有限修改

模拟反馈一：“其他都可以，但不要略向姚澄，岑宁始终朝柜。按这个改完继续。”

Agent在S01仅改岑宁朝向及必要观看：她始终朝柜说首句，不改变录音机持物。机位保持能看到姚澄看锁、伸手与录音机距离；岑宁的脸不被擅自补成回头反应。台词与三声钟先后不变。完成相关接点回查后，交完整S01修订稿让用户确认本次产物；不重问已确认的本场方向，也不逐镜询问。“改完继续”不自动表示新稿已经看过。用户确认新稿并选择做Prompt时，可人工拿取整份稿继续。

模拟反馈二（替代一，不能同时适用）：“这里有点弱，重新考虑。”

这是修改请求，不是采用。Agent先定位主稿中关系压力是否因为早切手特写而丢失，形成一个完整有限候选并交回；不能把模糊评价解释成允许删钟声、加反转或自动进入Prompt。

## 下游回传怎样处理

Prompt若把“听完三声再收物”写成“钟声中收物”，由Prompt修自己的表达，导演稿不需要让步。若真实预演证明导演候选机位根本看不到姚澄看门锁，而关键锁点不能丢，分镜只改覆盖/开放机位，再回读看锁到伸手过程。若新机位改变已审重要观看方向，交该范围重审；不要重写原词、灯光或另一场。

载体意见“这句太长”也不是自动删词许可。Agent先判是表格显示、生成容量还是创作意见，再返回对应职责；不能把每种反馈都当成导演重做请求。
