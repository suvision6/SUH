# 按观看目的选择光学组合

仅在该效果承担本场观看任务或用户明确要求时使用。先沿[空间依据](Spatial-basis.md)确定相机能站在哪里、主体离它多远、什么需要读清，再选景别与光学关系；不因调用本文件就改已采用机位、加入雾或锁定器材。

| 观看目的 | 写进镜头过程的组合 | 需要核对的条件 |
|---|---|---|
| 远处窥视或隔着环境观察 | 固定远距观察点＋长焦取景；用实际存在的门边、柱或枝叶作近前景遮挡，把主体保留在可读区域。有已定尘雾/热扰动时，利用相机到主体之间的空气层表达距离 | 遮挡不能盖掉剧情必须看见的动作；没有雾就不补雾，不写固定遮挡百分比；换主体不自动换观察位置 |
| 远距跟随、压缩层次 | 相机仍在远处，长焦从该位置收取前后主体；以跟摇/必要的小幅修正保持行动在取景内 | 前后层次来自既定距离，变焦不替代相机移动；压缩观感不授权把远物搬近，也不强加手持抖动 |
| 贴近小物看出周围空间 | 相机靠近对象、采用广角取景，近物占据显著前景，实际背景向深处展开；写明低位或平视、接触面与仍需可读的环境 | 这是近远透视效果，不是把道具本体变大；若要求物理巨物，另给真实尺度锚。镜头不可穿进物件 |
| 近身广角的人物感受 | 在允许的近距离观察人物，保留周围行动空间；指定脸/手与环境各承担什么信息、是否需要同时可读 | 不机械加浅景深、夸张脸部畸变或鱼眼；“人物清楚、环境也需识读”须与焦点安排相容 |
| 同镜内靠焦点揭示 | 写起始焦点对象、暂不清楚的层面；在源动作/发言触发后将焦点移到具体对象，使那一信息首次可读，说明另一层随之如何变化 | 焦点转移不是切镜、变焦或移机。保持已定摄影位置与连续过程；不同时要求所有层面全程清楚又靠失焦藏线索 |
| 人物主观或FPV穿行 | 指明观察者/摄影机身份、高度关系、可通行路线、拐点和落点，沿路线呈现空间；运镜与人物运动分别有主语 | 人物主观不自动变无人机飞行；不能穿过已闭门墙，画内手/器材仅按实际设定出现。速度变化、停留和转场服从本场，不强制永不停机 |

镜头句只留下本次实际采用的组合。例如已有门边与远距机位时，可写“相机留在走廊尽头，从近处虚焦门边旁看室内人物；长焦保持她的手和桌上信封可读”，不抄整行配方。若采用方向要求空气层、当前场景却没有依据，先解决风格/空间设计范围，不以术语补造环境。

同一连续镜中，未设计改变的机位、取景和光学效果应稳定；采用的推拉、变焦或移焦须写各自触发、过程与结果。多Cut可以有不同光学，不能为一致性锁成全场一个镜头；不机械在段首段尾重复“镜头锁定”口令。已有具体焦距/FOV照有效设计继承，开放输入按画面效果选用，缺传感器、距离等依据时不做焦距与FOV的伪精确换算。

回读时核对最终正文能否同时实现所承诺的可见面、遮挡、相对尺度和焦点先后。文字可说明设计关系，不能认证真实镜头几何、生成景深或可读字形。
