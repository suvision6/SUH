# 绘图输入、导出与采用

## 依据分层

绘图正文从主稿的当前有效状态派生；稳定依据、全场档案与时点恢复机制见 [Spatial-and-state.md](Spatial-and-state.md)。本文件规定整页与单格输入如何自足装配。接收当前Prompt时同时读取其有效版本、上游导演锁定与已落实开放摄影，按 [Handoff.md](Handoff.md#有效内容与各阶段消费)确定依据；生成边界不改成片Cut。

按[简笔表达与参考职责](Style-and-reference-roles.md)实际看图并分配场景、人物、服装、道具用途；每张仅取指定部分，统一黑白导演简笔表达。前页只可延续已核对的对应维度，风格不合格不作为画风依据；整图参考存在泄漏可能，文字限定不构成保证。选参考不产生导演采用。

不能读取图就写对应未验证项，不假装看过，也不无端阻塞文字工作。复制正文仅列本次必要素材的职责与明确占位符，用户最后手动映射实际素材或 @ 标签；不列未采用素材或库存清单，不用上传／绑定状态阻塞文字预演。占位符不是已附图证据。实际调用时按 [Media-execution.md](Media-execution.md)核对正文标签与真实附件，返图再按采用维度回看；不能把写了路径称为参考已生效。

局部快检只装配目标单格或必要小组，补足能判断本次问题的状态与接点即可；不要求全场主稿。单格走下方“单格生成与修图输入”，小组按实际格数选择版式，不沿用完整预演的默认九槽。完整预演仍交请求范围内的全段主稿和所有实际页。

## 整页复制输入的装配

每页必须交实际填好的正文，不能只交下列空模板。页数随内容变化，每页复制文本均可单独使用：

页槽只表示排布，稳定格ID不随分页变化。改变本页行列、格序或空槽位置时，同步复制正文中的排布、逐槽内容和未用槽；启用媒体工具时还须同步media.pages的layout与完整slots。默认3×3，其他版式行列各1—4；脚本保存装配依据，但不会替作者把旧正文改成新版式。

```text
绘制一张〔行×列，默认3×3〕顺序故事板，按左到右、上到下阅读。每格画幅〔实际画幅〕；白纸黑白导演简笔分镜：用粗略概括线抓大形与结构，脸部低细节、衣服简化，人体体块与关节方向足以辨认动作；仅以少量浅灰交代必要明暗和空间深度。背景只留当前取景需要的空间锚点、开口、台面、通路及遮挡；不做纹理装饰渲染或清稿漫画。格内仅剧情画面，台词/字幕/气泡/生产编号留在图外。
参考与用途：〔逐张写实体、指定取用部分、适用页/格和待映射占位符，或本轮无图片参考〕；只继承这些职责，全部转为统一黑白简笔；参考的相机、构图、姿态、背景、精细材质和色彩画风不自动继承。
稳定依据：〔本页人物各自的辨识轮廓、必要固定物的朝向/连接/通路与世界光源；不夹全场状态档案〕。
页首状态：〔此刻人物位置、持物、门/帘/道具状态；不是全场最终状态〕。
第1格：〔源镜/候选镜与当前时点；固定摄影或运动中的当前相机位置/朝向；人物位置、身体/头部朝向和目光对象；画内脸/肩/手、固定物与接触/遮挡〕。
……逐格实写，不用“同上”省略不同状态。
第N格（最后一格）：〔实际内容，或未使用、留白〕。
连续性：〔同镜内未动锚点的投影/相对尺度，或真实摄影路径带来的变化；跨页接点、全局人物身份、当前衣发/道具状态及有源依据的变化；少而具体〕。
摄影边界：遵守逐格有效景别、角度与构图，不为动作可见擅改镜头；关键信息不可用粗线或灰面盖掉。
```

每格一个时点。需要两次动作先后就分格，或选一瞬并在主稿写过程；不要画“先开门再走出去”复合残影。机位写到能区分透视即可，无必要不用 FOV 数值。依[同镜投影](Spatial-and-state.md#同镜多格与跨页的连续投影)展开：机位/朝向/焦段/画幅固定时保留未动背景的投影与尺度；连续运动按每格真实位置、朝向和摄影变化推导。同镜跨页的两份正文都写当前摄影、关键画内锚点与当前状态，不能笼统强制运动机位相同，也不能只靠“与上页相同”。前景肩归属、可见脸/手、身体与头部朝向、视线和遮挡分开推导，不强制每格三层景、不强制镜头动。

最终正文的连续读回、投影核对与修改同步由 [Workflow.md](Workflow.md) 执行；投影判断依据见 [Spatial-and-state.md](Spatial-and-state.md)。

白纸石墨不认证色相/最终质感；色彩关键线索保留在文字主稿，必要时标该预演媒介无法验证，不能私加图案代替。剧情实物文字按来源，可读性需要实际图验证。未使用格留白且不计为有效画格，不填重复图、不加“结束”等图内字。

## 单格生成与修图输入

单格生成正文同样自足，不能从整页复制输入中只摘一句动作。只展开该格必要条件，不带其他格正文、全页未来变化或全场档案：

```text
绘制单格净图，画幅〔实际画幅〕。白纸黑白导演简笔分镜：用粗略概括线抓大形与结构，脸部低细节、衣服简化，人体体块与关节方向足以辨认动作；仅以少量浅灰交代必要明暗和空间深度。背景只留当前取景需要的空间锚点、开口、台面、通路及遮挡；不做纹理装饰渲染或清稿漫画。参考与限定用途：〔本格必要素材的实体、指定取用部分及映射，或无图片参考〕；只取指定部分，统一黑白简笔，不自动继承参考摄影、姿态、背景、材质和色彩画风。
稳定依据：〔本格人物辨识轮廓、必要空间/固定物与光向〕。当前是〔源镜/候选镜＋时点〕，〔人物位置、身体/头部朝向、目光对象、当前持物/接触〕。
相机〔相对位置、朝向、景别；运动镜另写本格路径位置〕，画内〔前景归属、脸/肩/手与固定物可见部分、必要遮挡〕。〔与本格有关的固定投影或路径约束〕。遵守有效景别和构图，不为动作可见擅自扩镜。净图不加台词、字幕、气泡和生产编号。
```

只在有实际可访问目标图时叫“修图”；没有图则叫“替换绘图输入”。正文需独立复制：目标实际文件/明确格位置 + 当前时点 + 改变 + 保留 + 必要关联。示意：

```text
以已提供的〔目标图〕〔第几行第几列〕为编辑底图。当前是〔时点〕。调整〔明确目标〕到〔可见正确状态〕，同时校正〔与目标直接相关的接触/遮挡/承重〕。保留〔已核对身份、景别、机位、其他手和物件、必要空间关系〕；统一白纸黑白导演简笔、低细节人物、必要浅灰，明确本次参考只取〔指定部分〕。目标图是编辑底图，不自动作画风标准；仅修其他问题且原媒介合格时保留其表达，修风格时将改变范围写明。仅返回该格〔实际画幅〕净图；格内不加生产标签或字幕。其他格不作为编辑对象。
```

不能承诺像素级不变；实际结果要比较。目标藏在已锁近景外不擅扩镜，只说此格不可验证并给未采用对照。若是整页图要明确只返回单格还是重排该页，不让模型顺带改其他格。更多原因定位与复核见 Media-review.md。

## 交付内容

完整预演主稿包含请求全段声画、候选镜头/时点、来源和用户有效修订；局部快检保留本次目标、必要接点和明确的未检查范围。复制正文均与本次主稿同源。简单正文可聊天交付；批量用 [Delivery-tool.md](Delivery-tool.md) 本地保存，文字交付器本身不会绘图。准备工具原样选择页copy_text或格current_input，既不按主稿标题隔离档案，也不自动补全当前状态；参考职责与简笔表达须已写入copy_text/current_input；references[].purpose不自动注入prompt。实际调用只传对应prompt与本次真实附件，不再粘贴整个Bundle/主稿。实际图片执行、版本及按维采用机制见 [Media-execution.md](Media-execution.md)，交付和回交流程见 [Workflow.md](Workflow.md)。图、框外标签、过程格和未采用备选不自动成为正式Cut或首尾帧。
