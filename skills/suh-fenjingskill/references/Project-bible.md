# 项目设定（可选）

用于短片、短剧、长剧集等跨场、跨集的一致性。**没有项目设定也能正常工作**；单场任务不需要建。

## 何时建立

- 同一角色、场景或道具会在多场/多集反复出现；
- 用户提供了角色图、场景图、服装表或世界观设定；
- 已经出现过跨场不一致（发型、服装、房间布局、光线方向前后对不上）。

## 写什么（只写会重复用到的）

| 卡片 | 内容 |
|---|---|
| 角色卡 | 名字、辨识外观（脸型/发型/体型的少量关键特征）、服装阶段（按场或时间段列出）、标志性持物、声线与语言 |
| 场景卡 | 固定入口/固定物/通路、世界光源与常用时段的照明惯例、可复用的空间依据版本 |
| 道具卡 | 承担剧情的物件外观、数量、状态变化节点 |
| 风格基线 | 画幅、整体影调、全片统一的摄影倾向（如“偏固定观察、少运镜”） |
| 时间线 | 角色服装/伤痕/道具状态在哪一场发生变化 |

素材占位符沿用用户手动映射的方式，项目设定只写用途，不代表已上传或绑定。

## 优先级

1. 用户本轮明确修订
2. 本场原文与已采用的场级设计
3. 项目设定
4. 本轮必要暂设

场内事实与项目设定冲突时，按上面顺序执行并标出冲突位置。已明确授权的修订及其对应资料同步可直接完成，保留来源、适用场次或时间段；超出授权的新设定或推广范围仍交候选，不把本场暂设自动扩成全项目事实。

## 各 Skill 怎么用

- **分镜**：建立场级空间依据前先读相关场景卡和角色卡，继承其中的固定物、光源惯例与当前服装阶段。
- **Prompt**：【主体、关系与场景】与【保持一致】从角色卡、场景卡取真正不变的部分；服装阶段按时间线取当前值。
- **Image9**：按上述优先级继承人物辨识轮廓和固定物；变化状态按当前时点恢复，供多页、多场沿用。

项目设定不是新增审批，也不要求逐场填表；只在确有重复使用时维护。
