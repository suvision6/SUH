# 表演延续与局部修补

同一角色跨场出现、已有表演约定，或收到“太僵、过满、像换了一个人”等反馈时使用。普通单场不要求主档，也不增加固定节拍、微动作或表演评分。先用现有故事与采用依据完成本次范围，不另跑一套导演流程。

## 同一个人，适配这一场

从已有角色卡、采用稿或用户明确说明取相关依据，分清：

- **较稳定的表演特征**：这个人惯常怎样对待他人、做决定或表达自己；已给的动作习惯及其触发、适用关系，已知声线与语言。只保留真正会复用的少量特征及来源/采用范围，不由照片、职业或体型推导心理、口音和人生经历。
- **当场处境**：他此刻想从谁那里得到什么、双方关系怎样、当前知道什么、用什么策略；从源刺激到回应，不提前表演尚未知晓的结果。
- **累计状态**：前面已发生的受伤、疲劳、情绪余波、关系或策略变化。按剧情时点恢复，不因新场开头回到中性，也不把后场变化倒灌到早场。

稳定特征要落到当前处境中的可见/可听表现，不能每场复制同一个眨眼、攥手或停顿。已有习惯只有触发和身体条件均成立、且符合本场有效设计时才使用；当前不适用可不出现，不强行转换成另一个怪癖。声线身份可以延续，语速、气息、强弱和沉默仍服从本场来源及已定节奏。

只将本镜需要的表现写入人物当前状态、实际动作/发声处；镜头看不见的微表情不能承担观看任务。跨场继承不是全文粘贴角色主档，也不让同一人物永远保持同一姿态、情绪或权力位置。

已有角色卡可附一句“已采用表演特征—触发/适用范围—已发生的变化”；也可直接留在本次主稿的简短依据中，无固定字段或新项目档案。继续使用[项目设定的优先级](Project-bible.md#优先级)：本场原文与采用设计不被习惯模板覆盖。局部修订只影响实际适用的场次/时点，不全局替换同名角色。

**没有主档时照常完成。** 依据本场原文、关系和可见行为写作；独立创作的开放表演可作本场选择，但不把一次选择晋升为长期性格，不凭空补标志性动作、口音、创伤或秘密。未来需要复用且用户已采用的特征再保留。

## 反馈落到哪一处表现

先对齐实际Prompt/采用稿、反馈和可读媒体；只有文字反馈时称用户描述。下面是按需诊断方向，不要求每场逐项检查，也不因命中一行自动得到改戏权限。

| 所见或所述问题 | 先查什么，如何做最小修补 |
|---|---|
| 只等自己台词，反应像开关 | 找听者真正获知信息的时点、正在做的事及原有回应。可补清已采用的刺激与行为关系；来源要求“话落后才……”就保留，不统一提前到话中。 |
| 用表情替代行动，近景演得过满 | 区分原设计与Agent未经采用的装饰动作；把遗漏的既有目标/行动写清，只删未经采用的冗余，不擅自减掉已采用动作。不能为了看到手换掉已锁近景。 |
| 提前愤怒、松气或演出结局 | 回查此时实际知道什么及触发是否已发生，恢复有效源的认知顺序；不能靠改台词、偷换动机或加镜头补理由。 |
| 群戏人人同样反应 | 分清各人是否听见/看见、当前任务与关系。保留来源里的不同反应或不反应，避免泛写“所有人震惊”；不强制错开固定半拍，也不为热闹给每人加动作。 |
| 跨场像换人，或伤情/情绪被重置 | 对照稳定特征、当前目标/关系与累计状态，修错误重置或生硬照搬；不要靠每场重演同一微动作证明“还是他”。 |

已在做的动作可以被信息打断，但须来自本场原文、有效设计或明确开放选择；不为“自然”给角色新增擦杯、玩硬币等副动作。一个可见停顿可能已足够，不把停顿都填满。具体示意见[跨场与局修例](../examples/Performance-continuity.md)。

## 区分写清与改变采用内容

格式整理、补清指代/作用范围、把实际原话放回发声处，或非创作的生成分组可以直接完成；仍保留已锁镜头、切点、时长与声画先后，不用分组掩盖重剪。独立创作或上游明确开放的维度，按已有授权完成，不反复求批。

若修法需要改变**已采用的动作、台词、镜头、切点/时长、关键节奏或故事事实**，先给“原内容 → 具体冲突 → 拟改法及受影响部分”，作为候选供用户确认，再将获确认的改变写入执行稿。“太僵”“更自然”本身不等于同意换动作、改词、提前回应或改拍法；已有明确针对该改变的确认则直接落实，不重复确认。原采用稿保留，未受影响部分照常完成。

按[既有回读](Workflow.md#6-先读实际会演出的过程再核对来源与承接)交目标段完整新版，并按[Handoff](Handoff.md#入口与审阅)等用户看过确认；改法已获授权也不免去新稿确认。对照保留原话、动作发生顺序、摄影及前后状态；涉及跨场特征的实际变更按[变更影响](Active-context.md#具体变更如何处理)定位范围。没有真实结果时只报告文字修订与待验证项，不把描写更细当作表演已经变好。
