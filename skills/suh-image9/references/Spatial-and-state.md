# 当前时点恢复与摄影投影

在恢复每页/格当前状态时使用本文件；关键接触、视线、反打和同镜多格需进一步推导，写完复制输入后读回。它支撑整段观看和叙事预演，不把预演改成空间测绘；没有空间歧义时使用必要相对关系，不给每格添加坐标或方位表。

## 先恢复时点，后推导画面

在同一预演主稿内分清三种信息：

- **稳定依据**：稳定称谓/明确别名及足以区别人物的脸、发、体型和服装轮廓；场景中影响当前画面的门窗、通路、固定物与世界光源；真实参考的采用维度。未知普通外观可作少量暂设并跨格继承，不给所有人同一通用脸，不擅加剧情标识。表情、朝向、目光和持物不是永久身份。
- **状态档案**：发生变化的源节点/镜内时点 → 变化前 → 路径或动作 → 变化后。记录必要的转身、起坐、接触、松手与持有；未动对象保持，不因换镜或换页重置。短任务可用几句文字，不要求额外台账。
- **当前有效绘图输入**：恢复目标时点后，只带这页/这格需要的稳定依据及当前状态。全场历史、未来结果、未采用方案留在主稿，不作为每页共同初态。页面可以包含依序变化的各格，但每格只画自己的时点。

按剧情时序恢复，不能按文件时间或最新成图恢复。例如档案是 A 在门口持信、B 到桌旁尚持信、C 放信后离开：逆序回补 A 时仍在门口持信；同刻换角度仍是 A，不因 C 已画完就让 A 空手。单格输入不带其他格或全页未来动作；页首状态也不复制整场终态。文字不完整时由 Agent 在主稿展开，不让用户重填表。

在主稿中显式分段保存这些信息；[模板](../templates/Previs.md)给出填写位置。标题用于组织作者工作，本包脚本不会按标题自动排除状态档案：Agent须把恢复后的页/格正文写入copy_text/current_input，再从实际待交正文读回。工具保存成功不能证明作用域正确。

参考按实际采用维度约束：脸型参考不继承照片姿态；场景布局不继承拍摄视点；道具外形不决定当下持有人；摄影只在实际采用范围内锁定。身份错误图不成为身份锚；仅风格不合格图的有限使用按[参考职责](Style-and-reference-roles.md)核对，不能传递画风。场级稿中已有有效布局、手位和观看决定先继承，开放部分才新增候选；直接剧本路线的独立候选不自动进入其他路线的 Prompt。

## 投影要落实到这一格

先读真实描述中的摄影机位置与朝向，再检查人物/目标相对该视点的关系。分清世界方位、人物自身左右、画面左右。需要判断视线或手位的格，至少能回答：相机从哪边看、朝哪里，人物身体/头部朝谁、眼睛看谁，哪侧脸/肩/手可见，目标落在哪个画面方向，谁遮住谁。身体未转而眼睛侧看是不同状态；不能用“面向画左”代替对象关系，也不能只写“不越轴”代替画内结果。

已有绝对方位时，使用当前相机朝向推导，而不是凭人物身份或上一镜画左画右沿用。下表只用于地面近水平视点、画面上方未旋转的常见情况，**不是给所有场景指定坐标的要求**：

| 相机朝向 | 画面右对应世界方向 | 画面左对应世界方向 |
|---|---|---|
| 北 | 东 | 西 |
| 南 | 西 | 东 |
| 东 | 南 | 北 |
| 西 | 北 | 南 |

斜向机位按当前看向转动左右参照，不能就近套正北。需要精确判断而已有平面位置时，可将“主体到视线目标”的平面方向与相机画面右方向比较：同侧分量为画右，反侧为画左，近乎正对/背对则不硬写向左/右。这只给常规近中心构图的侧向基准，不是透视投影求解器。主体明显偏轴、目标有较大前后深度差时，还要比较主体与目标相对相机的视线夹角；不能仅凭世界侧向分量断言屏幕位置。仍须另外判断人物朝向、景别和遮挡；目标可能在画外或相机一侧，不能因知道它的方向就让它入画。

例如人物在近中心构图中，摄影机朝北，人物看向其东南侧目标，侧向分量是画右；同一人物/目标换成朝南摄影，则为画左。相机朝东，目标在人物东北侧，侧向分量为画左；相机朝西则为画右。只改变机位不会改变人物自身左右手、道具归属或房间布局。若目标方向、相机朝向或镜面关系不足以唯一判断，就写确定的相对关系或将开放摄影补清，不猜一个画左/画右。

还要检查画内能否看见：背身者身体前方持物可能被躯干遮住；过肩前景不能同时成为面向相机的完整正脸；关系正确但画幅外的手只能标未验证。灯源仍留世界位置，换机位后可见亮面可以变化。需保留的未知身份与悬念，不因侧脸变清楚而提前泄露。有意越轴/镜面/倾斜机位按实际视觉关系推导，不从上表机械裁判。

## 同镜多格与跨页的连续投影

同镜不是每格重新设计构图。先按采用摄影判断：

- 机位、朝向、焦段与画幅固定：未动固定物的画内位置、相对尺度与透视保持；人物只按该时点有依据的位移、转身和表演变化，不为重新居中而相对门/桌漂移。单纯人物动作不让背景换尺寸或旋转。
- 连续运动：每格落在同一摄影路径的实际位置、朝向及采用焦段/画幅上，由此推导投影、尺度与遮挡变化；不能把全部格冻结在起始机位，也不能把推近画成人物走近。变焦与移机分开，同刻备选不混成运动过程。

固定物写出决定空间可读性的关系，例如长边朝向、两端连接和可绕行口；不靠“某物在画右”把横向结构画成沿侧墙的纵向结构。只写当前景别能看见且叙事需要的轮廓，不为展示全屋擅扩景别。

跨页延续同一镜时，两页独立正文都展开当前摄影、未动锚点和人物时点；固定摄影的背景沿用同一投影，运动摄影从页尾路径位置继续。核对页尾→页首，也核对前面同镜格，不能因为分页而重设空间或拍摄距离。换镜保持同一世界，允许合理投影变化。

## 最终正文的投影依据

投影判断对象是实际待交的页/格复制正文，不能由空间总述推定正文正确。同一摄影保留未动部分的投影；肢体归位、道具移开或人物转身后，只按变化后的轮廓与桌沿等前景重判关联遮挡，尤其区分“已经空手”与“当前构图可见空手”。人物、目标或摄影变化会影响相关格。

结果记录定位到必要格，包含当前机位/朝向、推导的画内侧别/可见面/遮挡及正文是否一致；普通无歧义格无需抄表。跨页同镜每页各有当前摄影和状态。无图只称文字投影核对；投影正确也不证明整段因果、情绪或声画成立。执行时机与读回顺序见 [Workflow.md](Workflow.md)。

## 修复保持有效成果

输入错时同步修主稿中对应依据、实际格正文及受影响页复制输入；保留其他页/格的文字或文件，不通过全场重写修一个方向。改动如果涉及共同布局或身份，应按真正适用时点检查依赖，不能只改一次词也不能无条件全场替换。修后将新旧内容对照，说明改变了哪些格、哪些相邻接点重新核对、其余正确内容是否保持。未改文件可做字节比较，改页内的未改格应逐格比对。

真实图错时，先读图再针对目标写修图输入；实际返图重新观察目标与关联接触/遮挡，检查原先正确内容未退化。没有返图，只能确认修订输入的保留范围，不能声称图像已修好。结构工具和文件哈希不会理解摄影投影，也不能替代上述读回。
