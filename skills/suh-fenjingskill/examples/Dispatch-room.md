## 原始任务与完整来源

模拟请求：“把以下两场做成场级导演稿，偏克制的悬疑；不要逐秒拆成镜头，关键观看由导演设计，普通执行细节让后续 Prompt 决定。不要改台词，不补列车里的画面。两场都要完整，不要只交方向分析。没有硬总时长，没有指定导演或 DP，没有实际图片或音轨。”

Agent 给连续来源建立定位；下列编号不是原作者镜号。

**U01 / 第一场，夜，内，调度室。** 宋禾面向东侧控制台，右手握着钥匙。梁远站在西门内侧。控制台上方的红灯一直亮着。西门开着，走廊的白光从门口照入。

**U02。** 宋禾没有回头，说：“车上还有人。”

**U03。** 两人沉默十二秒，宋禾仍握着钥匙。走廊脚步声随后接近，在门外停住。

**U04。** 门外一个男声说：“检修完成，可以送电。”发言者不入画。

**U05。** 梁远朝控制台跨出半步，停住。宋禾这才转头看他，说：“你说过，里面是空的。”

**U06。** 梁远不答，垂下目光。宋禾将钥匙放在控制台上，离开房间。红灯仍亮着。

**U07 / 第二场，紧接，夜，内，走廊。** 宋禾走出调度室，在门外走了三步后停下。西门仍开着；她身后的梁远没有走出来。

**U08。** 同一个男声从走廊远端问：“怎么还不开？”始终看不见他。

**U09。** 宋禾转身关门，停两秒，说：“钥匙不在我这儿。”

**U10。** 门内传来钥匙与台面相碰的轻响。宋禾没有回头。走廊灯熄了一盏，其余灯仍亮着。她仍站着。

注意：原文先说门外脚步停住、后说同一声音来自远端。两场之间并未写该男人怎样走远；这不允许 Agent 擅加身份揭示。需要保持这段短场连续时，可将该声音的空间移位列为局部待确认，先完成其余确定部分。

## 初次交付 / 候选导演稿 R01

来源：上列 U01—U10 全部；尚无人类改句。教学前提：模拟用户已确认克制悬疑、保留双人关系与等待、不揭示门外或列车真相的方向；不是实际项目采用证据。状态：本次正式导演方案仍为候选，正文完整；未获采用。男声位置的连续性存在一个局部未决，不影响主体行动、对白、关门与收尾的设计。

### 导演判断

第一场把权力放在谁仍握钥匙、谁能走向控制台，以及谁要求对方承担解释。宋禾的首句是她的声称，不补拍乘客证明其真假。梁远的沉默和低头可以被观众理解，但不写成已经认罪。第二场让宋禾把操作权留在屋里；钥匙声只证明屋内发生了声响，不插入梁远拿钥匙送电的画面。结尾一盏灯灭也不替代“送电已经发生”的事实证据。

本例不硬配导演/DP姓名。摄影采用一个明确方法：优先让人物与控制台的距离形成关系，观众暂不进入门外发言者视点。光线来自已写明的门口走廊白光和红灯，红灯只作局部颜色/状态线索，不凭一盏指示灯照亮整张脸。若关键右手看不清，选能同时看到手、台面及门口受光的观察范围，不在反打时搬动光源。

本例比较过两个实质方法：以宋禾主观范围为主、把梁的反应延后，能增强宋的不确定，但容易丢失他半步试图接近控制台的关系；保持两人和控制台关系的观察，能使十二秒等待与半步行动在同一空间成立，代价是较少依靠密集面部细节。本候选选后者。这里只比较方法，不虚构某位大师对此剧本的判断。实际落实在首场空间建立、十二秒的关系保留、半步到转头的先后三处；第二场借门与画外声延续受限信息，不再用浅景深或大幅运镜遮掉关键交接。

### 第一场：调度室

起始用中全景关系观察，同时交代宋禾面向控制台、梁远留在西门内侧以及两人的距离。观察方向选在人物连线南侧作为本稿候选组织，能辨认宋禾握钥匙的右手，红灯在控制台上方持续可见。不是把每个后续机位固定在一个坐标；可以在不误导空间的前提下改变覆盖。

宋禾不转身，朝控制台方向发言。宋禾（室内现场）：“车上还有人。”梁远仍在门口；不要把他此刻的表情加码成惊恐或默认撒谎。

话结束后给足十二秒无对白的等待。宋禾仍握钥匙，两人未改变原站位。这里保留关系，不强迫每隔几秒发生攥拳、吞咽或看门。保持中全景同框，让两人和钥匙的关系承受完整等待，不用切换压缩十二秒。十二秒之后，走廊脚步由远接近，在门外停住。

镜头仍在门内观察，门外男人不入画。男声（西门外画外）：“检修完成，可以送电。”两人听完整句，梁远才向控制台跨出半步并停住；宋禾随后转头看向他。这段保持同框；宋禾转头后切到能见她的脸及右手所握钥匙的中近景，由关系压力递进到她要求回应。必须让观众辨认梁远还没有走到台前、宋禾仍握钥匙，以及转头由半步行动触发。宋禾（室内现场）：“你说过，里面是空的。”这句发言进行中，机位留在人物连线南侧，由宋禾缓摇到梁远侧面中近景；落幅看清他的脸与视线，完整问句在此镜内结束，宋禾出画后的声音仍在室内现场持续。

保持梁远侧面中近景，看见他听完后不回答、目光落下，给观众读清这次无回应；这是候选节奏安排，不增加口型、闪回或事实解释。宋禾开始放钥匙时，按原切点转回能见双方及台面的中景，宋禾把右手钥匙放到控制台可见的平面并松手，再离开房间。此时钥匙归台面承重，不能跟着她的右手离场，也不能切到梁远已经接过。结束时红灯仍亮、梁远仍留在屋内、西门仍开着。

候选补充：上述关键景别、方向与切换、落钥匙的可读范围，以及无答复的计划阅读长度。原文没有指定的衣着、面貌和门外男声身份保持未定，不借参考图补设定。

### 第二场：走廊

走廊采用沿门口向远端看的中景，承接宋禾从西门走出后的运动，她在走廊走完三步后停下。开着的西门在她身后；梁远未出来。不要再演一次从控制台拿钥匙离开。开场不需要重复首场对白，也不以新场为由让她恢复中性表情。

男声（走廊远端画外）：“怎么还不开？”发声者始终不入画。此处按原文保留“远端”，与上一场门外位置如何连接列为未决；不得在稿里偷改成贴近宋禾耳边。宋禾听完，转身去关门。三步形成的离门距离要由实际走回/伸手动作解决，不能关一扇隔空的门；本稿选择她折返门口的最小必要过渡。这是导演补足动作路线，不意味着她重新入室。

关门过程中保持门与宋禾同框；门关好后切到仍能见门与远端灯的宋禾侧面中近景，停两秒。宋禾（走廊现场）：“钥匙不在我这儿。”不给门内反打，也不显示手伸向钥匙。门内传来钥匙与台面相碰的轻响；宋禾已经面向走廊，不回头。走廊的一盏灯熄灭，其余灯继续亮，她仍站着。结束在这段持续的站立上，不补离去、哭泣、决断或事故结果。

门响、钥匙声、灯灭是各自发生一次的事件。男声和钥匙声不变成室内可见人物的口型。声音不额外叠加音乐；本例未作配乐选择，后续若要加入，仍需保持这些信息能被听清。

### 锁定与开放

保护事实：原字对白及发生顺序；十二秒沉默；男声始终画外；先半步、后宋转头；钥匙先放稳再离手；宋离屋时无钥匙；第二场三步后停；关门后两秒；钥匙声在台词后；宋不回头；只灭一盏走廊灯。未重列的 U01—U10 同样有效。

关键观看：首场不能提前给出列车内真相；宋转头不能早于梁半步；必须看到钥匙放下，不能仅靠第二场台词补证据。第二场钥匙声只以画外证据进入，不插入取钥匙人的身份或动作。

关键设计：首场南侧中全景保持等待及半步；宋转头后中近景追问，问句中镜内摇向梁远侧面中近景并保持至无答低头可读；放钥匙转回关系中景；次场走廊方向中景，关门后侧面中近景保住门与灯。开放给 Prompt/Image9：在既有镜头/Cut关系内微调运动实现并组织生成分段。本例已开放在发言期间以镜内观看看听者，不增Cut或重复对白；这不是对其他分镜的通用许可。南侧组织目前也是未采用候选，不应向下一阶段谎称为用户硬锁定。若按本候选继续，它仍需作为当前方案清楚继承，改掉需说明具体观看收益，不能无声漂移。

### 时间依据

本例没有音轨，以下全部是计划估计。为初步排布暂用每分钟180中文汉字作为本例假设，不是 Skill 通用默认；标点和人物名不计。未宣称实际最短时长。

第一场三个发言共21字，粗估7秒。另有来源明确十二秒沉默。脚步接近/停住计划2—3秒，梁半步至宋转头计划1—2秒，无答低头的阅读计划2—3秒，放钥匙/松手/离开计划4—6秒。上述按正文分别先后发生；问句中的镜内换看与该次发言同期，不另加占时，无答低头仍在话后保留上述阅读时间。第一场合计约28—33秒。

第二场两个发言共12字，粗估4秒。走三步/停下计划2—3秒，折返关门计划2—4秒，门关后来源明确两秒；台词后的钥匙声、一次灯灭与站立阅读放在同一收尾观察内，计划3—5秒。第二场合计约13—18秒。两场约41—51秒，男声位置的最终处理可能改变场间接续，但不能靠删除十二秒沉默凑短。

时间区间来自计划假设，逐段相加支持内在检查；实际脚步路径、门的位置和表演尚未验证。精确镜头分配由后续合法执行组织决定，不能拿41秒总量反写为若干精确小数镜头。

### 局部未决与可交接范围

U03的门外停步与U08的远端男声：建议确认“男人已经退到远端”还是“第二场的远端应改为门外”。目前两者都不写进事实正文。不能直接用“声桥”解决人物实际位置矛盾。除该处声源接续外，两场完整方案可以进入文字评审；主线仍先等待本次用户审阅；只有用户明确采用且可独立处理的范围，才交 Prompt 继续。

交给 Prompt：以上完整正文和锁定/开放、有效来源；不要只发两句导演意图。它继承采用的关键观看，规划生成段与开放执行细节；当前未提供任何实际资产，不能声明 @image 已可用。若用户要求Image9完整预演，交两场叙事、站位、钥匙与声画关系；若只快检放钥匙的观看，就交该处及必要前后状态，不扩成整场。两路都保留相关未决，每次预演物料交用户确认，不自动替换导演稿或启动下游。
