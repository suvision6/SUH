# 斯坦利·库布里克

**标签：中心透视 / 广角深焦 / 精确运动 / 制度空间 / 概念硬切**

## 时间与剪辑

- 低覆盖、冷静停留，让人物自行暴露荒谬或恐怖。
- 不急于用近景解释心理。
- 硬切可跨越巨大时间、文明或观念距离。
- 场景时长服从空间与制度逻辑。

## 摄影机运动与视角

- 固定、轨道、推进、变焦和斯坦尼康均精确使用。
- 运动让人物无法逃离空间秩序。
- 摄影机像制度、机器或无情观察者。

## 构图、空间与调度

- 超广角、中心构图、单点消失线和深景深。
- 建筑、走廊、地面图案和轴线统治人物。
- 人物沿轴线运动，位置像制度中的节点。

## 适用

- 制度压迫、军事训练、封闭体系、人物异化。

## 禁止

- 只追求对称和广角；
- 几何不表达权力或控制；
- 长时间停留却不改变观众判断。
