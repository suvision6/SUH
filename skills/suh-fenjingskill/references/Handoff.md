# Agent调度与有效交接

各Skill完成本次专业创作并交完整可审物料，每次产出均由用户确认；Skill之间可由用户人工衔接。这里约定材料怎样拿取和理解，不自动触发下一环节，不增加总控或第四个必选Skill。

## 入口与审阅

| 当前请求 | 路线与继续条件 |
|---|---|
| 剧本到导演/Prompt主线 | 正式分镜前先确认或继承本轮导演方向；分镜完成主稿与内部复核后，再交用户确认本次物料。用户选择进入Prompt时，只承接已实际采用且仍有效的范围。 |
| 用户要求用已审场级/精确稿写Prompt | 读取采用版本、范围与实际合同，直接承接已确认物料；不重复批准同一决定，新的Prompt产物另交用户确认。 |
| 明确独立Prompt创作、快速测试或修补 | 在请求范围内完成导演与生成组织，无分镜/Image9前置；无分镜短文按用户明确时长设计，只询问真正缺失且影响执行的时长或约束，已有锁定内容容纳不下则定位冲突；不能由Agent把未审主线改名绕过。 |
| 快速静态检查、完整预演或预演修订 | 按用户本次范围进入Image9；快检接指定关系及必要上下文，完整预演可独立读剧本或接场级/精确稿。每次产出交用户确认，不把预演设为Prompt前置。图片生成、编辑和重试按实际任务授权，文字准备不以缺图停工。 |

“采用/按这版继续”按本次已交付物料的语境与范围记录，无固定口令。用一句话回显实际确认的范围与版本；用户已把同一已确认物料交给下一Skill时，不重复确认同一决定。打开文件、Agent自查、导出成功或图片已生成不等于人类采用。修改后交新的完整候选让用户确认，先前“按这个修改后继续”不等于新产物已经看过并采用。部分采用只适用于对应范围；有实质歧义只问具体接点，不逐镜加审。确认物料本身不自动启动其他Skill。

Excel正文改动是人工修改输入，意见/批注须结合上下文区分建议与决定；导入器不判断其语义。原返还文件及原稿保留。载体操作见 [Review-delivery.md](Review-delivery.md)。

## 有效内容与各阶段消费

交接按本次范围包含实际来源/版本与反馈、相关声画、初末态、信息与时间锁点、明确开放摄影、有效对白、采用的导演/DP方法及必要素材用途；完整预演保持全段声画，局部快检保留目标与必要上下文。空间依据保留事实、实读证据和暂设的来源/版本，按 [Spatial-basis.md](Spatial-basis.md)继承与局部更新。普通短场可放同一主稿；只有用户要求维护既有跨调用记录时才参考 [Workflow-state.md](Workflow-state.md)，不按文件时间猜“有效”。

已确认的方向、故事与约束底稿可同时作为分镜和美术概念的依据，注明适用范围及实际确认来源；两线可人工交换空间、观看与外观需求，不必等待全部资产完成。方向确认不替代任何本次物料的产出后确认，也不新增汇合审批。

- **分镜→Prompt：**交当前有效的实际镜头、景别、关键机位、调度、动作时间与声画/Cut关系，默认继承，不需用户另说“锁定”。Prompt可准确写清已有决定、落实明确开放的微调，并组织生成分段、容量与接续；生成请求分组不等于重剪，段落、表格行、Beat或Image9格不自动等于Cut。改变已有设计或遇真实冲突时定位影响并回交该范围，其他可独立成立范围继续。
- **分镜→Image9：**完整预演交请求范围完整戏与采用设计；快速静态检查只交指定镜头、衔接、空间或动作关系及判断所需前后状态、锁定与上下文，不强制扩成整场全套。必要上下文不自动扩大绘图范围，局部结论不外推到未检查镜头。预演物料由用户确认，相关反馈可回分镜；静帧不验证运动。Image9可跳过，不构成Prompt前置。
- **当前Prompt→Image9：**同时交当前有效Prompt的版本/范围、它继承的导演锁定及在开放范围内已经落实的摄影增量；快检只取本次指定关系及必要前后状态。Image9按这份实际执行设计恢复时点；生成段边界不是新增Cut。开放范围内的落实不另设逐项审批，本次输出仍交用户确认；改变导演锁定或仅属未采用备选的内容不能混成当前依据。两份来源冲突时定位具体范围，不能用较新文件自动覆盖。
- **Image9→Prompt：**回交本次实际检查范围、具体发现与未验证项；作为新依据使用的内容只限实际采用维度及声画/镜内时点关系。同镜多格不增Cut，图不自动变成首尾帧；布局采用不连带摄影、身份或图中偶然细节。缺图仍可完成文字Prompt；Image9发现只交证据和建议，本次物料由用户确认后决定是否接入或修改分镜/Prompt，不自动回写。

视频Prompt采用两层交付：外层记录依据、必要素材占位映射、计划总长、设置及接续；内层独立可复制，格式与时间规范由 suh-promptskill 的 `references/Output-format.md` 统一定义，入口数值统一取 `references/Generation-profile.json`（同时安装 suh-promptskill 时以该包文件为准；分镜与Image9运行不依赖这两个文件）。提交生成单元总长为profile范围内的整数秒，Cut内部可小数。有分镜输入（含场级/精确采用稿）的实际Cut默认均有连续计划范围，单Cut也写；明确不用时间戳只省略范围，仍保留Cut编号与合规整数总长。无分镜独立入口保留自然段与导演功能，未要求估时、未给提交总长的非提交草稿不强造时间表；测试名称本身不豁免已有分镜的默认。此时间规则是本次用户定制，不要求分镜或Image9职责照抄Prompt时间表。正文只保留必要素材的逐主体职责，用户最后手动映射/@，不列未采用库存；默认无字幕但保留对白与剧情文字。实际提交前核对绑定，不把占位符说成已上传。审阅载体选择不改变已定的Prompt正文规范。

DP与导演参考落实为同一套本场决定；没有选定姓名也能工作，下游不另选参考推翻上游。

## 修改和失败回到哪一职责

| 实际问题 | 先处理的位置与保持范围 |
|---|---|
| 关键反应不可见、空间或揭示顺序不成立 | 分镜修观看/调度；改变已审关键方向只回交受影响范围。 |
| Prompt歧义、漏动作、生成单位过载 | Prompt修实际正文和合法分段；不能删剧情、改词或提速圆预算。 |
| 预演时点、投影、接触或真实图执行错 | Image9修目标及关联接点，不把错误图倒灌成导演事实。 |
| 素材指错、参数或版本对不上 | 执行环节恢复实际输入；不能仅加长提示词。 |
| 载体丢字、乱码或反馈读回错 | 从同源有效稿修载体并回读，不重写创作。 |
| 实际媒体未提供或不可读 | 记录证据缺口；不把未知判成模型错或创作通过。 |

先读真实证据，再定位变化单元和前后接点；保留无关正确正文、旧版与批注。新候选不自动替换有效稿，工具未检测到变化也不证明没有依赖。按本职责Workflow完成实际正文读回后，交完整修订稿、真实差异与未决范围。确定性校验、Agent专业判断、用户采用和真实媒体表现分别报告。
