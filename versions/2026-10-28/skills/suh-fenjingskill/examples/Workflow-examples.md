# Workflow 举例

本文件只存放 [Workflow](../references/Workflow.md) 中较长的举例，不含额外规则。

## 2. 决定观众和人物各自知道什么

- 改变剧情的反例：把“他说箱里没人”拍成空箱证据，是改变剧情，不是强化画面。
- 可检验的观看路线示例：“先让观众看见手仍扣住门闩；听到门外完整答话后才看见她松手；不提前给门外人的身份”。

## 3. 让行动在空间里可发生、可看见

- 关系可读的示例：观众需要看见“拒绝接物”，就必须有递交和未接的关系；不能只拍独立两张脸。
- “做完”不等于“读懂”的示例：手已收回、脸已转过，不证明观众看清犹豫或决定。

## 4. 把导演与 DP 参考变成少量有效决定

- 隐瞒戏的两种方法：同一段隐瞒可以采用“与人物保持距离、让对方的等待在同框里持续”，也可以采用“限制在追问者的视野、迟延得到回答者反应”；前者保存关系压力，后者强化信息不对称，两者不是靠替换色调实现的风格差异。
- 导演与 DP 冲突示例：导演希望保留双人关系、摄影参考却倾向极浅景深遮掉一人时，先解决可读性取舍再写稿。
- “参考落实”写法示例：“十二秒等待保持双方关系；完整问句后才给回答者反应；关门隔断后只保留室内声音”。

## 6. 核对声画占时并完成正文

- “把她的手笼住，接着问：‘冷吗？’”不能仅凭备注写“捂手与问话同期”就按最大单项计时。
  - 若采用方案是捂住后发问，给两个先后过程留位。
  - 若已有采用决定明确要求捂手时发问，则正文写清动作进行中发问。
  - 前者不被判为失败拍法，后者也不是通用省时规则。
