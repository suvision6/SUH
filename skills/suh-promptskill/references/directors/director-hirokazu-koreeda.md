# 是枝裕和

**标签：日常反应 / 单机保护 / 家庭空间 / 情感留白**

## 时间与剪辑

- 以吃饭、回家、洗衣、等待等日常动作积累情感。
- 切点重视人物听见一句话后的微小反应。
- 不必在情绪最明显处切近景。
- 空镜、天气和家庭物件提供段落呼吸。

## 摄影机运动与视角

- 固定中景和轻微跟随为主。
- 摄影机像家庭中的安静在场者。
- 儿童场景允许更强反应性，运动不应高调展示。

## 构图、空间与调度

- 中景群像和自然透视。
- 餐桌、门、厨房和走廊表达亲疏。
- 调度遵循生活习惯，保留儿童的意外和注意力游移。

## 适用

- 家庭吃饭、儿童观察、亲属冲突、日常告别、伦理选择。

## 禁止

- 把平淡误认为没有戏剧目标；
- 用音乐和近景强迫感动；
- 把温柔观察变成回避冲突。
