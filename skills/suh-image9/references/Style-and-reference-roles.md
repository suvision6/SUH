# 导演简笔表达与参考职责

## 预演的完成尺度

默认采用白纸黑白导演简笔分镜，粗略概括线、必要浅灰，先读清构图、景别机位、空间深度、视线、动作姿态、接触遮挡和前后连续性。脸用低细节轮廓与少量表情线；衣服用轮廓和必要标识；建筑用大形与结构。完成度服务剧情和摄影信息，不做纹理装饰渲染或清稿漫画，也不把人物简化到无法判断动作的火柴人。

简化的是画法，不是内容。开口、台面连接、可走路线和动作所需几何必须保留；黑块/灰面不能盖掉关键信息。按上游实际采用的景别、角度、构图和可见范围画，不能为看清动作擅自扩镜或换镜。取景与动作要求冲突时，回传具体镜/格及不可见项；替代拍法单列未采用。用户明确另定媒介时按其要求调整，仍保留预演定位。

行业也有精细稿和彩色稿；这里选择适合本用户快速预演验证的缩略导演草稿，不复制任何艺术家的个人笔法或原作面板。

## 一张参考只承担指定的职责

可同时用场景、人物、服装、道具参考；先实际查看，再为每张写“实体＋取用部分＋适用范围”。同图兼任多职须分别说明。只取指定部分并统一转换为上述黑白简笔表达，不按原图1:1重绘。

| 参考职责 | 提取到当前预演的内容 |
|---|---|
| 场景 | 可见布局、固定物朝向与连接、入口/开口、通路和空间深度；未显示部分保留未验证或有依据的暂设 |
| 人物 | 可辨的体型、脸部轮廓、发型；低细节也能区分人物 |
| 服装 | 衣服轮廓、穿戴层次与剧情必要标识 |
| 道具 | 形制、相对尺度、必要非对称细节及指定角色/对象归属；当前持有人和接触按剧情时点恢复 |

这些参考不自动带入相机、构图、姿态、背景、材质细节、色彩或画风。确有已采用的摄影参考时，另列具体摄影职责，不能由场景或人物参考暗中解锁。参考与源稿锁定冲突时报告冲突，不让图片覆盖有效上游。

多页共用全局人物身份及当前有效衣发/道具依据，不逐页重新设计。剧情导致外观状态变化须标源节点和发生时点；姿态、表情、视线随当前剧情变化，不锁在参考姿势。没有参考就依据文字和必要暂设继续，不能假造参考或声称已查看/绑定。

## 前页图片不是默认画风锚

前页生成图先按拟采用的维度核对，不能因“已经生成”就成为依据。风格不合格的前页不再作为画风参考；若身份/衣发部分另经实际核对正确且确需延续，可明确只取这些部分，错误维度不继承。身份本身不合格就不能作身份锚。

整图参考仍可能把色彩、渲染、构图或错误细节一起带入，文字限定不能保证消除泄漏。优先回到职责明确的原始参考；确需沿用前页时只选必要图并在当前输入写清用途与统一简笔表达，返图对照检查。发现继续串用就调整参考选择/表达方式或回传问题，不无限叠加否定词，也不扩大重生范围。

## 职责必须进入实际生成正文

每页 copy_text、需执行的每格 current_input 及修图正文，都要自足地包含本页/格的简笔表达、参考职责和当前状态。媒体记录的 references[].purpose 是审计字段，不会自动加入 prompt；不能只在台账写职责、实际调用却遗漏。

文字阶段可用明确待映射占位符；真正调用时，先查看每张参考和编辑底图，按当前宿主支持的附件机制实际绑定，并对照保存的 prompt、附件及用途。路径、标签和准备记录不证明模型收到了图片；无支持能力不得静默丢参考，未暴露实际载荷如实留证据缺口。返图检查身份、衣发/道具、空间、构图和简笔表达各维度，不把“已附图”当执行正确。
