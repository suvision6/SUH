# Agent调度与有效交接

三个Skill各自完成专业工作，每次物料产出交用户确认；可由用户人工衔接，不默认自动触发下一Skill。Image9可选，一旦运行其本次结果也须人工看；不把一次结果确认拆成逐格、多重审批，也不增加第四个必选Skill。

## 入口与审阅

| 当前请求 | 路线与继续条件 |
|---|---|
| 剧本到导演/Prompt主线 | 分镜完成主稿与内部复核，交用户审阅；只为已实际采用且仍有效的范围写Prompt。 |
| 用户直接给已审场级/精确稿 | 读取采用版本、范围与实际合同，直接进入Prompt；不重复批准同一决定。 |
| 明确独立Prompt创作、快速测试或修补 | 在请求范围内完成导演与生成组织，无分镜/Image9前置；无分镜短文按用户明确时长设计，只询问真正缺失且影响执行的时长或约束，已有锁定内容容纳不下则定位冲突；不能由Agent把未审主线改名绕过。 |
| 完整预演、局部快检或预演修订 | Image9可独立读剧本，也可接场级/精确稿或当前Prompt；按实际请求完成整段覆盖，或只检查指定镜头/接点及必要上下文。图片生成、编辑和重试按实际任务授权，文字准备不以缺图停工；Image9是可选旁路，不是进入Prompt的前置验收。 |

“采用/按这版继续”按语境与范围记录，无固定口令。Agent依语境判定采用或条件性继续时，继续前用一句话写明将视为已采用的范围与版本，用户可即时纠正；这不是新增审批。打开文件、Agent自查、导出成功或图片已生成不等于人类采用。仅要求修改就交新候选；“按这个修改后继续”覆盖指定修改与依赖回查，本次新物料仍交用户确认后再衔接下一Skill。部分采用仅作为已确认范围的依据，不自动触发下游；有实质歧义只问具体接点。

Excel正文改动是人工修改输入，意见/批注须结合上下文区分建议与决定；导入器不判断其语义。原返还文件及原稿保留。载体操作见 [Review-delivery.md](Review-delivery.md)。

## 有效内容与各阶段消费

交接按本次范围包含实际来源/版本与反馈、相关声画、初末态、信息与时间锁点、明确开放摄影、有效对白、采用的导演/DP方法及必要素材用途；完整预演保持全段声画，局部快检保留目标与必要上下文。空间依据保留事实、实读证据和暂设的来源/版本，按 [Spatial-basis.md](Spatial-basis.md)继承与局部更新。普通短场可放同一主稿；已有跨调用记录按 [Workflow-state.md](Workflow-state.md)恢复，不按文件时间猜“有效”。

- **分镜→Prompt：**交当前有效的实际镜头、景别、关键机位、调度、动作时间与声画/Cut关系，默认继承，不需用户另说“锁定”。Prompt可准确写清已有决定、落实明确开放的微调，并组织生成分段、容量与接续；生成请求分组不等于重剪，段落、表格行、Beat或Image9格不自动等于Cut。改变已有设计或遇真实冲突时定位影响并回交该范围，其他可独立成立范围继续。
- **分镜→Image9：**按实际请求交接。完整预演交请求范围完整戏与采用设计，Image9完成候选镜头、镜内时点和所有实际页；局部快检只交指定镜头/衔接/空间/动作问题、有效设计及足以判断的前后状态和空间依据，不要求整场全套。必要上下文不自动扩大绘图范围，局部结论不外推到未检查镜头；静帧不验证运动。
- **当前Prompt→Image9：**同时交当前有效Prompt的版本/范围、它继承的导演锁定及在开放范围内已经落实的摄影增量。Image9按这份实际执行设计恢复时点；生成段边界不是新增Cut。开放范围内的落实不新增逐项审批，本次物料仍须人工确认；改变导演锁定或仅属未采用备选的内容不能混成当前依据。两份来源冲突时定位具体范围，不能用较新文件自动覆盖。局部快检只展开指定问题及必要上下文，不把全部Prompt生成段自动扩成整场预演。
- **Image9→Prompt：**回交本次实际检查范围、具体发现与未验证项；作为新依据使用的内容只限实际采用维度及声画/镜内时点关系。同镜多格不增Cut，图不自动变成首尾帧；布局采用不连带摄影、身份或图中偶然细节。缺图仍可完成文字Prompt；Image9发现只交证据和建议，本次物料由用户确认后决定是否接入或修改分镜/Prompt，不自动回写。

视频Prompt采用两层交付：外层记录依据、必要素材占位映射、计划总长、设置及接续；内层独立可复制，格式与时间规范由 suh-promptskill 的 `references/Output-format.md` 统一定义，入口数值统一取 `references/Generation-profile.json`（同时安装 suh-promptskill 时以该包文件为准；分镜与Image9运行不依赖这两个文件）。提交生成单元总长为profile范围内的整数秒，Cut内部可小数。有分镜输入（含场级/精确采用稿）的实际Cut默认均有连续计划范围，单Cut也写；明确不用时间戳只省略范围，仍保留Cut编号与合规整数总长。无分镜独立入口保留自然段与导演功能，未要求估时、未给提交总长的非提交草稿不强造时间表；测试名称本身不豁免已有分镜的默认。此时间规则是本次用户定制，不要求分镜或Image9职责照抄Prompt时间表。正文只保留必要素材的逐主体职责，用户最后手动映射/@，不列未采用库存；默认无字幕但保留对白与剧情文字。实际提交前核对绑定，不把占位符说成已上传。审阅载体选择不改变已定的Prompt正文规范。

DP与导演参考落实为同一套本场决定；没有选定姓名也能工作，下游不另选参考推翻上游。

## 修改和失败回到哪一职责

| 实际问题 | 先处理的位置与保持范围 |
|---|---|
| 关键反应不可见、空间或揭示顺序不成立 | 分镜修观看/调度；改变已审关键方向只回交受影响范围。 |
| Prompt歧义、漏动作、生成单位过载 | Prompt修实际正文和合法分段；不能删剧情、改词或提速圆预算。 |
| 预演时点、投影、接触或真实图执行错 | Image9修目标及关联接点，不把错误图倒灌成导演事实。 |
| 素材指错、参数或版本对不上 | 执行环节恢复实际输入；不能仅加长提示词。 |
| 载体丢字、乱码或反馈读回错 | 从同源有效稿修载体并回读，不重写创作。 |
| 实际媒体未提供或不可读 | 记录证据缺口；不把未知判成模型错或创作通过。 |

先读真实证据，再定位变化单元和前后接点；保留无关正确正文、旧版与批注。新候选不自动替换有效稿，工具未检测到变化也不证明没有依赖。按本职责Workflow完成实际正文读回后，交完整修订稿、真实差异与未决范围。确定性校验、Agent专业判断、用户采用和真实媒体表现分别报告；本次成果先交用户确认，记录工具只保存已有决定，不替用户确认或自动推进。
